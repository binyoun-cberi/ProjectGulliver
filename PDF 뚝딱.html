PDF 뚝딱

학습지와 안내문 PDF를 하나로 합치고, 필요한 쪽만 골라 저장하거나 나눠 보세요. 설치나 로그인이 필요 없어요.

1. PDF 파일 준비

여러 장의 학습지나 가정통신문을 추가할 수 있어요. 파일을 넣은 뒤 ↑ ↓ 버튼으로 순서를 바꿀 수 있어요.

여기로 PDF 파일을 놓으세요 또는 아래 버튼을 눌러 내 기기에서 선택하세요 한 파일 최대 70MB · 전체 150MB · 암호가 걸린 PDF는 지원되지 않을 수 있어요

    2. 어떤 작업을 할까요?

    PDF 합치기

    2개 이상의 PDF를 위 목록 순서대로 한 파일로 만들어요. 학습지 여러 장을 하나로 묶을 때 편리해요.

    먼저 PDF 파일을 추가해 주세요.

    필요한 페이지만 골라 저장

    필요한 쪽만 새 PDF로 만들어요. 3,1,2처럼 원하는 순서로 적어도 돼요.

    실제 PDF의 첫 쪽은 1이에요. 범위: 1-3, 낱장: 5

    PDF 나누기

    긴 문서를 정해진 페이지 수마다 나눠요. 결과 PDF마다 저장 링크가 생겨요.

    한 번에 20개까지 분리할 수 있어요.

    페이지 회전

    가로로 눕거나 거꾸로 된 페이지를 돌려 저장해요.

    고급 PDF 편집

    PdfCraft의 원본 편집기를 뚝딱교실 안에서 실행해요. PDF 보기, 주석, 페이지 구성 등 다양한 편집 도구를 사용할 수 있어요.

    알림: 현재 PdfCraft 원본의 고급 편집기 메뉴는 영어예요. 이 화면의 PDF 간편 도구는 한국어로 제공돼요. 휴대폰에서는 화면이 좁으므로 PC나 태블릿을 추천해요.

    3. 완성된 PDF 저장

    파일 이름을 눌러 내려받으세요. 새로고침하면 만들어 둔 결과는 사라져요.

    학급 자료를 이렇게 정리해 보세요

    1. 주간 학습지 — 요일별 PDF를 순서대로 합치기
    2. 가정통신문 — 보내야 할 쪽만 골라 저장
    3. 수업자료 — 2쪽씩 나눠 모둠에 배부하기
    4. 스캔 문서 — 방향이 틀어진 페이지 회전하기

    원본 PDF는 그대로 유지돼요. 변환한 파일은 새 파일로 내려받습니다. 암호·전자서명·특수 양식이 있는 PDF는 변환 후 반드시 검수해 주세요.

    기술: 오픈소스 PdfCraft(고급 편집)와 pdf-lib(간편 작업). 두 라이브러리 모두 사이트에서 직접 제공하며, 파일은 브라우저 안에서 처리해요.
