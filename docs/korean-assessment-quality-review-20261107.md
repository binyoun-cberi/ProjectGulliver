## 검수 범위와 상태

- 자동 검증: 지문 ID 중복, 학년군별 분배, 5문항 구성, 선택지 유일성, 정답 포함, 해설 및 평가 요소 태그를 검사한다. 자동 테스트가 교육적 정답의 유일성을 완전히 입증하지는 않는다.
- 원전 확인: 고전의 핵심 사건과 구절을 아래 자료에 대조하였다. **출처 확인은 학생용 문제 최종 검수 완료가 아니다.**
- 종교적 중립성: 교리나 신앙적 진위를 묻는 문항 대신 이야기의 사실, 인물의 행동, 배경, 중심 내용을 평가한다.
- 저작권: 공개 고전의 줄거리와 취지를 바탕으로 문장을 새로 작성하고 출처와 창작 응용 사례를 구분한다. 현대 번역문을 통째로 복제하지 않는다.
- 음성: 브라우저가 제공하는 Google 한국어 음성이 있으면 우선 사용하며 다른 목소리로 대체될 때 안내한다. Google Cloud TTS 유료 API나 외부 중계 서버를 연동하지 않았다.
- 결과: 교사/학생이 동의형 저장을 체크하고 학생 코드를 넣었을 때만 현 기기에 점수·평가 요소별 정오답을 저장한다. 실명, 본문, 선택한 답안 원문, 전체 문제 내용은 저장하지 않는다. 최대 100건, CSV 내보내기/전체 삭제 제공.

## 정답 및 난이도 검수 체크

1. 직접 정보 문항의 답이 본문에 있고, 추론 문항은 충분한 근거가 제시되는지 확인한다.
2. 선택지는 서로 의미가 달라야 하며 종교 신앙을 정답으로 요구하지 않는다.
3. 듣기는 정보 파악·순서·사건의 변화를 평가하고 암기 부담이 과도하지 않게 구성한다.
4. 오답 기반 취약 요소는 해당 평가의 참고 지표이지 개인의 능력을 확정하는 자료가 아니다.
