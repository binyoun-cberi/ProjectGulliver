# 클라시트 홈 개편

홈은 문제지·받아쓰기 준비와 수업 도구 실행을 중심으로 구성한다. 기존 첫 사용 안내가 중심 기능보다 위에 크고 반복적으로 배치되어 있었고, 홈의 과목 바로가기에는 한자가 없었으며 받아쓰기를 찾기 어려웠다. 추천 목록의 예전 시간 도구 이름도 통합 카탈로그와 일치하지 않았다.

## 구성

- 첫 영역: 국어·수학·사회·과학·영어·한자·사자성어 문제지와 국어·영어 받아쓰기.
- 수업 중 바로 사용: 실제 카탈로그의 시간 도구, 이번 수업 알리미, 낱말카드·퀴즈, 교실 자리 배정. 주소로 연결하여 표시 이름 변경에 영향을 덜 받는다.
- 별표로 고른 즐겨찾기, 최근 사용한 도구, 저장한 타이머·퀴즈·자리표를 실제 브라우저 기록에서 표시한다. 기록이 없으면 저장 방법을 안내하며 가짜 최근 항목을 만들지 않는다.
- 첫 사용 안내는 아래로 옮겨 세 가지 시작 방법과 닫기 동작을 유지한다.
- 홈 검색에 과목·받아쓰기를 추가하고 도구·저장한 활동을 함께 찾는다. 결과가 없을 때 안내와 결과 수를 제공한다.

기존 보관·복원·폴더·백업·즐겨찾기 저장 구조를 유지한다. 홈에만 적용되는 새 스타일을 별도 파일로 두고, 문제지 선택창과 교사 도구 내부 화면은 변경하지 않는다. 데스크톱 홈은 중복 왼쪽 메뉴를 숨기고 주요 메뉴와 영역별 이동 버튼을 사용한다. 모바일은 기존 작업 메뉴를 유지한다. 교사 도구·활동 목록 화면에는 기존 왼쪽 메뉴를 유지한다.

## 검증

완료 기준은 6과목과 2개 받아쓰기에 진입할 수 있고, 검색·즐겨찾기·저장한 활동 복원·모바일 메뉴가 실제로 동작하며 기존 저장 구조가 유지되는 것이다.

실행 명령: `node --test tests/clasheet-home.test.cjs tests/clasheet-first-start.test.cjs tests/clasheet-branding.test.cjs tests/classroom-workspace.test.cjs` (`NODE_PATH`, `CHROME_BIN`, 필요한 로컬 Chrome 라이브러리 경로 설정).

브라우저 검사는 320·390·768·1024·1440·1920px에서의 가로 넘침, 한자와 영어 받아쓰기 실제 이동, 과목·받아쓰기·도구·활동 검색, 검색 결과 없음, 즐겨찾기 새로고침 유지, 저장한 활동의 제목 HTML 이스케이프, 첫 사용 안내 닫기 유지, 교사 도구 목록 복귀를 포함한다. 저장 데이터 단위 검사는 활동 복제·보관·복원·폴더·백업 구조 보존을 확인한다.
