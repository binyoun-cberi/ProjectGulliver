# 핀볼 레이스 v3

수업에서 짧게 관전하며 참가자를 찾을 수 있도록 코스와 표시를 개선한다.

- 최대 30명을 같은 높이에서 겹치지 않게 출발시킨다. 명단은 매 경기 무작위로 섞는다.
- 열린 갈림길, 범퍼, 마지막 회전문을 사용한다. 순위에 따른 속도 변경은 없다.
- 1.8초 동안 출발 명단을 볼 시간을 준다. 이름을 겹치지 않는 위치에 배치하고 연결선을 그린다. 자리 부족 시 일부 이름을 생략하되 선택한 참가자와 선두를 우선한다.
- 명단에서 참가자를 선택하면 해당 구슬에 테두리를 표시한다.
- 남은 당첨 자리를 경기장 상단에 표시한다. 마지막 한 자리가 남으면 선두 구슬을 강조한다.
- 결승 판정은 매 물리 단계에서 수행하며 단계 내 통과 시각을 선형 보간해 정렬한다. 완전히 같은 시각은 구슬 번호 순이다.
- 모둠 배정은 기존 도착 위치 및 정원 규칙을 유지한다. 배정된 이름을 모둠별로 실시간 표시한다.
- 시간 제한에 도달해도 골인하지 않은 참가자를 도착 처리하지 않는다. 안내 후 실제 경기를 계속하며 교사가 설정으로 돌아갈 수 있다.

## 검증

30명 경기 seed 1~120 반복: 모두 30초 이내 자연 완주. 물리 시간 최소 19.07초, 중앙값 22.97초, 최대 28.72초. 일반 속도에서는 시작 안내 1.8초와 결과 표시 대기 시간이 추가된다. 1명/일부 등수 선택은 더 일찍 끝난다.

출발 위치별 1등 확률은 동일하지 않다. 참가자 이름을 무작위 위치에 배정하지만 이것만으로 통계적 공정성이 검증됐다고 주장하지 않는다.

Chrome 실행 파일이 없으며 다운로드도 실패해 이 환경에서 실제 화면 E2E는 미실행 상태다. 병합 전 브라우저 검사에서 30명 이름 읽기, 선택 강조, 7등 종료, 4모둠 균등 배정, 모바일 결과 표시를 확인해야 한다.

## 긴 코스 관전 개선

- 코스 높이 690 → 1,390, 결승선 574 → 1,274. 갈림길 → 좌우 경사로와 회전 급류 → 결승 범퍼로 구성한다.
- 자동 카메라는 선두를 따라가고, 명단에서 선택하면 해당 참가자를 따라간다. 선택 해제나 해당 구슬의 골인 후에는 선두 추적으로 돌아간다.
- 전체 코스 미니맵에 모든 미완주 구슬과 현재 화면 범위를 표시한다. 구간 진입 안내, 이름 표시, 마지막 자리 강조를 유지한다.
- 30명 seed 1~120 모두 실제 결승 통과로 완주. 일반 속도 물리 시간은 전원 도착 40.28~54.48초(중앙값 46.57초), 첫 골인 13.02~24.45초(중앙값 21.97초). 시작 안내 1.8초·결과 대기는 별도이며, 빠르게/초고속에서는 선택한 배속만큼 단축된다.
- 순위별 속도 보정이나 시간 만료에 따른 강제 골인은 추가하지 않는다.

## 핀볼 테이블 중심 화면과 조용한 관전

- 세로 테이블·상단 숫자 전광판·하단 참가자 선택으로 핀볼 기계 형태를 구성한다. 설정은 같은 테이블 안에서 열리고 경기 중에는 숨긴다. 설정 버튼으로 돌아가도 입력값을 유지한다.
- 출발/역전/구간 진입/개별 골인 해설 및 카메라 설명 띠를 제거한다. 도착 수·시간·남은 자리와 결과는 유지한다. 참가자 선택은 접어서 경기 화면을 확보한다.
- 중반 범퍼는 공통 시간에 따라 좌우로 이동한다. 범퍼의 물리 반발을 키워 추월 기회를 만들고 결승 구간의 반발은 약하게 유지한다. 순위에 따른 속도 보정은 사용하지 않는다.
- 30명 seed 1~120 반복: 전원 실제 골인, 일반 속도 물리 시간 약 40.52~63.07초(중앙값 45.92초). 시작/결과 대기는 별도.
- 출발 3.5초 이후부터 첫 골인 전까지, 새 선두가 0.5초 이상 유지된 횟수를 비교했다. 같은 seed 120개에서 기존 평균 2.8회 → 수정 평균 3.8회. 재미의 직접적인 증명과는 구분한다.

## 경로와 경쟁 장면 중심의 개편

- 넓은 화면을 사용하는 경기 뷰, 떠 있는 설정/순위/참가자 선택으로 기계형 프레임을 대체했다. 경기 중 공통 헤더를 숨기고 설정 버튼은 유지한다.
- 좁아지는 통로·중앙 섬의 분기·합류·서로 다른 장애물·마지막 회전문을 실제 충돌체로 만든다. 순위별 속도 보정은 없다.
- 고정 벽과 섬을 구슬 반지름만큼 확장한 격자에서 결승까지 경로 거리를 구한다. 현재 높이보다 실제 경로를 우선하며 골인은 기존 물리 스텝 통과 시각으로 판정한다.
- 대상과 경쟁 구슬을 함께 담는 카메라, 짧은 순위 흔들림에 대한 전환 지연, 분기 전체 보기, 당첨 경계와 결승의 확대/전체 슬로모션을 적용한다. 슬로모션은 고정 스텝을 바꾸지 않고 재생 빈도만 바꾼다.
- 30명 seed 1~120: 모두 실제 골인. 일반 속도 물리 시간 첫 골인 13.97~21.23초, 전원 도착 37.65~57.83초(중앙값 43.60초). 카메라 슬로모션·1.8초 준비·결과 대기는 별도다.
- 분기 구간 통과 기록 3,600건 중 왼쪽 719건/오른쪽 2,881건. 두 경로 모두 사용하며 위치별 통계적 공정성을 보장한다는 뜻은 아니다. 이름은 매번 무작위 출발 위치에 배치한다.
- 과거 높이 기반 선두 교체 수와 새 경로 기반 교체 수는 동일 지표가 아니다. 단순 횟수 증대보다 분기/합류 및 실제 경쟁 장면이 보이는지 브라우저에서 확인한다.
