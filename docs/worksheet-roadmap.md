# 문제지 완성도 점검과 다음 작업

이 표는 2022 개정 교육과정의 **성취기준 전체 충족표가 아닙니다.** `worksheet-coverage.csv`는 현재 화면에서 제공하는 학년·유형과 문제지 단위의 **일부 연계 연습** 표시만 나타냅니다. 국어 독해 지문에 따로 붙인 읽기 코드와 실제 학습 활동의 질은 문항별 검토가 필요합니다. 교육부 고시 제2022-33호의 별책 5(국어), 7(사회), 8(수학), 9(과학), 14(영어) 원문과 대조해야 합니다. 원문: https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0

`node scripts/worksheet-coverage.cjs`로 목록을 다시 생성할 수 있습니다. 각 행의 5·10·15·20문항은 현재 생성 가능 여부이며, 학습 수준의 적합성이나 모든 번호의 지면 검수를 뜻하지 않습니다.

## 이번 단계에서 완료

- 부족했던 짧은 지문, 중심 내용, 직업·생산·소비, 물질·날씨, 영어 문장·대화 문제 은행을 보강하여 모든 현재 유형의 20문항 생성 범위를 확보했습니다.
- 문항 수 선택을 고정 예외 목록에서 실제 유형 생성 검사로 바꿨습니다.
- 인쇄용 브라우저 검사에서 옛 24문항 조건을 20문항으로 고치고 국어 독해 4지문을 확인하도록 확장했습니다.
- 과학 3·4학년 식물의 한살이 관찰, 5·6학년 생태계 자료 읽기, 영어 3·4학년 짧은 글과 5·6학년 안내문·메시지 읽기를 각각 독립적인 20개 상황으로 추가했습니다. 모든 문항에 정답 근거를 붙였으며 학년군 밖에서는 선택할 수 없습니다. 특정 성취기준 코드는 문항별 원문 대조 전까지 표시하지 않습니다.

## 남은 단계와 완료 기준

1. **브라우저 지면 검수**: Chrome 환경에서 A4 학생용·정답 표시용, 5·10·15·20문항, 큰 글씨, 모바일 미리보기를 PDF와 화면 이미지로 확인합니다. 페이지 잘림과 정답 노출을 모두 검사합니다.
2. **학년군별 내용 매핑**: 원문 성취기준마다 현재 문항이 실제로 연습하는 기술을 연결합니다. 읽기·계산처럼 인쇄형 문제지로 확인할 수 있는 범위와 말하기·실험 등 별도 활동이 필요한 범위를 분리합니다. 코드 검토가 끝나기 전에는 연결 코드를 추가하지 않습니다.
3. **과목 내용 확대**: 새로 추가한 과학·영어 읽기 문제의 다음 단원 및 자료 유형을 확장하고, 수학은 계산 밖의 도형·측정·자료를 우선 추가합니다. 사회는 3·4학년과 5·6학년의 동일 문항 재사용을 줄이고, 국어는 문학·비문학의 질문 근거와 표현 활동을 강화합니다.
4. **교사용 해설 검수**: 정답이 왜 맞는지, 다른 보기가 왜 아닌지, 근거가 무엇인지 유형별로 붙이고 사실·표현·학년 적합성은 사람이 표본 검토합니다. 문항 수만 늘리기 위해 같은 뜻의 질문을 반복하지 않습니다.
