# 과학 문항의 맥락 검수

표의 숫자 변화만으로 원인이나 생명 활동을 단정하지 않는다. 질문에 답하는 데 필요한 관찰 대상, 관찰 방법, 비교 조건과 모형의 범례는 학생용 자료에 표시한다. 풀이에만 있는 조건을 학생이 추측해야 하는 문항은 수정한다.

기존 신규 자료 104개와 기존 그림·표 34개를 읽고, 신규 자료 중 33개에 필요한 상황·조건을 보강했다. 단순한 기록 비교처럼 제목과 자료만으로 대상과 기준이 분명한 문항에는 불필요한 이야기를 붙이지 않았다. 원인을 아직 알 수 없는 것이 학습 목표인 문항은 그 불확실성을 유지한다.

| 사례 | 부족했던 정보 | 수정 |
| --- | --- | --- |
| 수조의 물고기 수 | 밖에서 새끼나 알을 넣었을 가능성, 실제 출생 관찰 | 외부 유입 없음과 어른의 산란→그 알의 부화를 기록하고 성장·번식·운동을 구분 |
| 팔의 줄 모형 | 줄·막대가 무엇을 뜻하는지 없음 | 줄은 근육, 막대는 뼈라는 범례를 자료 앞에 표시 |
| 용수철 추 비교 | 추마다 무게가 같은지, 길이 기준이 무엇인지 없음 | 같은 무게의 추와 추를 달기 전 길이를 기준으로 한 증가량임을 명시 |
| 거른 소금물 비교 | 전후 시료와 증발 실험의 관계가 불분명 | 같은 소금물을 거르기 전후로 20g씩 덜어 비교함을 명시 |
| 소금의 녹는 양 | 소금을 차례로 추가한 것인지 독립된 컵인지 불분명 | 같은 온도의 물 100g이 담긴 별도 컵 세 개로 명시 |
| 물의 부피 감소 | 물을 덜거나 샜을 가능성 | 새지 않는 열린 컵, 추가·제거 없이 관찰한 조건 명시 |
| 흙의 물 빠짐 | 구간별 양인지 누적량인지 불분명 | 받는 용기를 비우지 않고 그때까지 모인 양을 측정함을 명시 |
| 지구 모형 | 전등도 움직였을 가능성 | 전등 고정, 지구 모형만 회전했음을 명시 |
| 생물 관찰 수 | 비교 구역·도구가 달랐을 가능성 | 비교에 필요한 같은 구역과 도구를 표시하고 시간 차이는 조사할 문제로 유지 |
| 습도와 마르기 | 온도·바람·젖은 양이 다를 가능성 | 같은 천과 물의 양, 온도·바람을 명시 |
| 쓰레기 줄이기 | 개수·질량·환경 영향 중 무엇을 우선하는지 불분명 | 먼저 줄이려는 기준이 개수임을 명시 |

`material.context`는 제목 다음, 표·그림 앞에 학생에게 표시한다. 선택형·OX·주관식·서술형과 교사용·학생용 인쇄에서 같은 상황을 읽는다. 일반 글씨와 큰 글씨 모두 기존 페이지 측정과 균형 분배를 따른다. 학생용 대표 5문항은 한 장을 유지하고, 전체 상황과 풀이가 담긴 교사용은 최대 두 장까지 검수한다.

검증: `node --test tests/daily-worksheet-core.test.cjs tests/daily-worksheet-formats.test.cjs` 및 CI의 실제 Chrome 인쇄 검사. 수조 문항의 유입 조건, 산란과 부화 기록, 같은 범주의 선택지와 4개 응답 형식 보존을 검사한다. 팔 모형 범례, 같은 무게의 추, 누적 측정값 등의 필수 조건도 회귀 검사한다. 이 검사가 모든 과학 문항의 교육적 적합성을 자동 판정한다는 의미는 아니다.
