# 네 과목 공통 학습 범위 선택

국어·수학·사회·과학의 차시별 화면에서 학기 → 단원 → 차시를 펼쳐 체크한다. 단원 전체 선택은 준비된 차시를 한 번에 담으며, 문항 수가 불필요하게 커지지 않도록 새 차시는 한 문항씩 담는다. 개별 차시 선택은 최대 다섯 문항을 기본으로 하되 실제 생성 가능한 수를 넘기지 않는다.

담은 차시는 왼쪽 목록에서 차시별 문항 수를 조정하거나 삭제한다. ‘현재 차시 담기’로 기존 단일 차시 선택을 옮길 수 있고, ‘선택 비우기’로 일괄 해제할 수 있다. 최대 40차시·총 40문항이며 각 차시는 최대 20문항과 실제 생성 가능 수 중 작은 값을 적용한다. 준비된 차시만 기본 표시하고, 준비 중 차시 보기로 아직 연결되지 않은 차시도 확인할 수 있다. 검색은 단원·차시 이름을 함께 찾는다.

수학은 같은 학년의 두 학기를 함께 보는 것이 기본이다. 다른 과목도 ‘1·2학기 함께 보기’로 같은 학년의 두 학기를 섞을 수 있다. 학년을 바꾸면 선택을 초기화하며, 두 학기를 함께 보는 중 학기를 바꾸어도 담은 차시는 유지한다. 한 학기만 보기로 바꾸면 다른 학기의 차시는 선택에서 제거한다. 학년을 넘어서 섞지는 않는다.

차시별 혼합의 `lessonMix`는 차시 ID와 문항 수를 보존하고, `mixTerms=all`은 두 학기 범위임을 나타낸다. 기존 한 학기 혼합 주소와 종합 연습의 `unitMix` 주소도 유지한다. 실제 문항 인덱스와 시드로 같은 문제를 다시 열고 큰 글씨 전환 시 문항을 보존한다. 수학은 같은 계산 유형에 연결된 차시를 여러 개 골라도 중복 식이 나오지 않도록 후속 차시에서 다시 추첨한다. 원하는 수를 채우지 못하면 명시적인 안내로 생성을 중단한다.

참고 화면의 출판사 선택이나 난이도 비율은 추가하지 않았다. 현재 연결된 목차와 문제 생성기가 제공하는 범위만 표시한다. 수학의 연결되지 않은 차시를 새로 보강하는 작업과 범위 선택 UI를 구분한다.

검증은 1~6학년 수학의 정확한 차시별 문항 수·중복 방지·시드 재현, 네 과목의 목록·선택·준비 중 표시·선택 해제, 수학 4학년 1학기 분수와 2학기 소수 혼합 및 주소 복원, 모바일·학생/교사용 A4 인쇄를 포함한다. 기존 사회 초성 혼합과 단일 차시 생성도 함께 검사한다.
