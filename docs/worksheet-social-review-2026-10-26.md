# 사회 문제지 검수 · 2026-10-26

## 재현과 수정

공개 GitHub Pages에서 사회 5학년 종합 연습 → 여러 단원 섞기를 열고 선사·삼국·고려·조선·근현대의 ‘초성으로 문화유산·인물 찾기’를 각각 5문항씩 골랐다. 객관식에서는 초성 없는 객관식, 단답형에서는 초성 없는 단답형 25문항이 나왔다. 주소와 행 선택은 보존되었지만 생성 과정이 `-initial`을 `-quiz`로 바꾸고 있었다.

- 역사 혼합은 각 행의 객관식·단답형·OX·초성 유형을 따른다. 모든 행이 역사 유형이면 상단의 공통 유형을 숨기고 행별 적용 안내를 표시한다.
- 초성 힌트형을 차시별 역사, 역사 성취기준, 종합 연습의 문제 유형에 연결한다. 한글은 초성, 숫자는 빈칸으로 표시하며 답안과 힌트의 일치를 검사한다.
- 초성에는 긴 설명문 답을 제외하고 짧은 이름·역사 용어 답을 사용한다. 문화유산뿐 아니라 개념도 포함하므로 행 이름에 ‘용어’를 명시한다.
- 예전 `-initial` 주소도 초성을 복원한다. 화면에서 단답형·OX 등으로 바꾸면 새 선택이 적용된다.
- 차시별 혼합은 현재 학년·학기의 차시와 차시별 수량을 사용한다. 종합 연습용 설정이 차시별 화면에 다시 나타나 선택이 무시되던 문제를 수정한다.
- 차시별 혼합의 주소·교사용 QR은 차시별 수량과 문항 인덱스를 저장한다. 큰 글씨와 재추첨 이후의 복원도 검사한다.
- 문항 수 오류 등으로 생성에 실패하면 이전 문제지를 지우고 인쇄를 막는다. 유효한 설정으로 다시 생성하면 인쇄를 복구한다.
- 서로 다른 시대가 섞인 역사 문제에도 역사 문항용 인쇄 배치를 적용한다.

## 범위와 검증

- 현재 연결된 사회 207개 차시, 38개 학년별 성취기준에서 지원 유형과 최대 문항 수를 이용한 문제지 1,556개를 생성한다. 동일 시드 재현, 중복, 정답·보기, 표의 열 수, 초성과 답의 대응을 검사한다.
- 사회 문제 은행 143개·2,521문항의 정답 포함 여부, 보기 중복, 필수 내용, 표 구조를 검사한다.
- 종합 연습에서는 5·6학년 × 다섯 시대 × 초성/단답/OX/객관식 × 공통 유형의 조합을 검사한다. 각 시대 5문항을 뽑은 25문항 혼합과 유형을 서로 다르게 섞은 조합도 검사한다.
- 실제 Chromium에서 데스크톱·390px 모바일, 새로고침, 큰 글씨, 학생/교사용 A4 PDF를 검사한다. 학생용에 정답이 노출되지 않고 25개의 초성 힌트가 모두 인쇄되는지 확인한다.
- 기존 사회·역사 자료, 문제 수 확장, 고려·조선, 줄 잇기·순서 배열과 다른 과목의 공통 생성·인쇄 회귀 검사도 실행한다.
- 최신 과학 확장과 맞지 않던 기존 DOM 검사의 ‘첫 과학 문제는 반드시 표’ 및 ‘2학기는 준비 중’ 가정을 실제 가용성 검사로 갱신한다.
- CI에서 일반 Chrome이 종료되던 두 브라우저 검사의 로컬 전용 단일 프로세스 옵션을 CI에서는 사용하지 않도록 한다.

문항의 역사적 사실을 새로 추가하거나 변경하는 작업은 포함하지 않는다. 재현한 생성·선택·답안·인쇄 결함을 수정하고 기존 내용의 구조와 연결을 검증한다.
