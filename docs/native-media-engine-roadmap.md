# 통합 캔버스 미디어 엔진 로드맵 (2026-10-14)

## 확인한 사실

기존 FilmCraft 0.7.2 / SoundCraft 0.6.1 번들은 Rust/egui로 만든 독립된 WebAssembly 애플리케이션이다. 웹 배포 파일을 iframe으로 삽입하는 것과 처리 엔진을 직접 이식하는 것은 다르다. SoundCraft의 문서에는 웹 빌드에 별도 제어 채널이 없다고 명시되어 있다. 필요한 기능은 업스트림 Rust 소스와 공개 라이브러리를 확인해 통합 캔버스에 직접 연결해야 한다.

FilmCraft/SoundCraft는 MIT 또는 Apache-2.0 선택 라이선스이지만 ArtCraft 상표/로고와 글꼴 등 제3자 저작물의 고지는 별도로 확인한다. 원본 NOTICE를 보존한다.

## 점진적으로 통합

1. **이번 1차 작업**: 선택 페이지에 MP4/WebM 클립 하나를 연결. 영상 시작 위치, 장면 길이, 음소거 미리보기. 원본은 동일 출처 IndexedDB에 저장하고 ZIP 복원 시 ID를 보정한다. 파일 크기 15MB, 최대 페이지 클립 20초, 실제 재생 가능한 브라우저 코덱만.
2. **다중 트랙과 타임라인**: 텍스트·이미지·영상·음악 각각 시작 시간, 길이, 트림, 배치·레이어와 기본 트랜지션. 기존 페이지 자료를 열 수 있는 마이그레이션.
3. **미디어 합성 출력**: MediaRecorder와 WebCodecs/Mediabunny 성능/형식 조사. 영상 소스와 배경음악 및 자막을 한 파일로 렌더링. iPhone Safari와 데스크톱에서 출력된 영상을 실제 디코딩해서 검증.
4. **세부 편집 기능**: 파형·페이드·음량, 마스크·크롭, 색보정·애니메이션 키프레임, 프레임/오디오 타이밍 정밀화. PC는 좌측 사이드바, 모바일은 하단바/시트라는 편집 동선을 유지.
5. **ArtCraft 프로젝트 호환**: 네이티브 프로젝트 파일 포맷과 안정적 변환 SDK가 확인된 경우에만 지원. 업스트림의 모든 기능/파일 형식에 대한 무조건적인 100% 호환 약속은 하지 않는다.

## 이번 단계의 범위와 명확한 한계

- 지금 추가된 클립은 **가져오기·현재 페이지 배경 연결·시작 지점/길이 수정·음소거 미리보기**까지만 지원한다.
- 원본 영상 내장 음성, 다중 영상 트랙, FilmCraft의 전문 효과, 클립을 포함한 최종 WebM/PNG/PDF 합성 출력은 아직 구현하지 않았다.
- 미구현 출력에서 영상이 조용히 누락되지 않도록 내보내기 전에 사유를 명시하여 거부한다.
- 비디오 원본은 프로젝트 문서의 메타데이터와 별개로 저장되므로 ZIP 전체 백업 권장. 브라우저 저장소는 완전한 클라우드 동기화가 아니다.
- 기존 고급 ArtCraft 편집기와 뚝딱 고급 영상/음악 프로젝트는 독립적으로 유지한다.

## 품질 검증

저장·복원·되돌리기, MP4 실제 재생 코덱, 용량/동영상 길이 제한, 페이지 재생 위치와 미리보기 동기, iPhone/PC 메뉴, 데이터 손실 없는 ZIP 복원, WebM/PNG/PDF 내보내기 제한 안내를 검사한다.
