# 뚝딱 제작실 3.2 — 통합 캔버스에서 WebM 영상으로 출력

## 제공 기능

- 3.1 통합 캔버스의 기존 페이지·글씨·사진·도형·애니메이션·장면 전환을 유지한 채, **영상 저장 (WebM)** 버튼 하나로 완성된 영상을 내려받습니다.
- 글씨·도형이 ‘서서히 나타나기 / 아래에서 올라오기 / 확대 등장’하는 프레임과 페이지 전환(바로·페이드·밀어 들어오기)을 20fps 브라우저 캔버스에 실제로 그립니다.
- 통합 캔버스에 연결된 로컬 WAV는 Web Audio API에서 읽어 MediaStream 오디오 트랙으로 합칩니다. 배경음악의 음량과 반복 설정이 적용되며 파일 자체는 서버에 올라가지 않습니다.
- 저장 중 진행률 표시, 중단 버튼, 완료된 WebM 파일 다운로드를 제공합니다.
- 녹화는 편집기 데이터의 복사본에서 진행하므로 편집 가능한 원본 프로젝트는 그대로 남습니다.

## 제약과 안전

- 출력 형식은 **WebM**, 해상도는 작업 크기에 따라 960×540 또는 595×842, 프레임률은 20fps입니다. 브라우저가 MediaRecorder의 WebM 녹화를 지원해야 합니다.
- **최대 길이 60초**입니다. 이보다 긴 프로젝트를 임의로 자르지 않고 길이를 줄여 달라고 안내합니다.
- WAV 파일을 연결했다면 실제 파일이 브라우저에 있어야 하고, 브라우저에서 디코딩할 수 있어야 합니다. 누락된 WAV 원본을 조용히 무음으로 대체하지 않고 오류를 보여 줍니다.
- 배경 탭으로 이동하거나 취소하면 불완전한 녹화물을 성공으로 표시하지 않습니다.
- 출력은 브라우저 성능과 미디어 API에 영향을 받으며, iPhone/iPad Safari에서 WebM 저장이 안 될 수 있습니다. 그 경우 **PC Chrome/Edge**를 안내합니다. MP4 직접 출력은 3.2 범위에 포함되지 않습니다.
- Chrome MediaRecorder가 만든 WebM은 전체 길이(Duration) 메타데이터가 비어 있을 수 있지만, 실제 인코딩된 프레임의 시각으로 영상 길이를 검사합니다. 일부 미디어 플레이어에서는 탐색 동작이 제한될 수 있습니다.
- 이 기능은 브라우저에서의 간단한 60초 이하 교육자료 영상 제작을 목표로 하며 FilmCraft의 전문 편집 기능을 대체하지 않습니다.

## 검수

- `tests/studio-v32.test.cjs`: 과거 모델 호환, 영상 길이·해상도 제한, 페이드·도형·글씨 프레임 렌더링
- `tests/studio-v32.e2e.cjs`: Chrome에서 두 장면과 애니메이션, 실제 RIFF/WAVE 신호를 포함한 WebM 생성 후 `ffprobe`로 VP8 영상과 Opus 오디오 트랙 확인. `ffmpeg`으로 서로 다른 장면 프레임 검증, 무음 프로젝트 및 취소·재시도 확인
- 기존 2.x/3.0/3.1 통합 검사, 공식 FilmCraft·SoundCraft WASM 검사를 계속 수행합니다.

## 앞으로

프로젝트 전체를 PPTX 등 다른 출력으로 직접 내보내기, WebM Duration 메타데이터 보강, MP4 로컬 인코딩 지원 여부, 실기기 Safari 호환성 검증은 후속 개선 후보입니다.
