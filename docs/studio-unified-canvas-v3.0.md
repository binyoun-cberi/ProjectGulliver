# 뚝딱 제작실 3.0 — 공통 편집 캔버스 (첫 단계)

## 목적

기존 제작실은 도안·발표·영상 등 서로 다른 편집기를 iframe으로 불러오고 이미지 파일로 전달했습니다. 3.0에서는 같은 프로젝트에서 **선택 가능한 텍스트·도형·사진과 여러 페이지**를 직접 편집하는 새로운 `통합 캔버스`를 제공합니다.

기존 도안·발표·문서·영상·음악·그림·PDF 편집기는 삭제하지 않습니다. 통합 캔버스는 기존 데이터에 영향을 주지 않는 새 종류(`canvas`)의 작업입니다.

## 3.0에서 직접 가능한 것

- 새 통합 캔버스: 16:9 발표 또는 A4 활동지
- 텍스트: 더블클릭 → 즉시 내용 수정, 글꼴 크기·색·정렬 변경
- 도형: 네모·동그라미·삼각형·별·선 삽입
- 사진: 로컬 PNG/JPG(최대 2MB) 삽입; 통합 캔버스 내부에서 이동·크기 변경
- 요소 선택, 포인터 드래그 이동, 모서리 손잡이 크기 변경, 복제·삭제·앞뒤 배치
- 최대 40페이지 추가·복제·삭제 및 하단 페이지 탐색
- 실행 취소·다시 실행 및 Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl/Cmd+D, Delete 단축키
- 선택한 페이지의 PNG 내보내기, 브라우저 인쇄→PDF 저장, 전체 화면 페이지 표시
- 기존 제작실의 IndexedDB 자동 저장/내 작업/ZIP 전체 백업 기능 그대로 사용
- 기존 도안·발표를 **통합에서 편집** 버튼으로 편집 가능한 새 캔버스 프로젝트에 복사. 원본은 그대로 보존

## 기존 도안/발표 전환 시 유의

도안의 요소별 위치·내용·색상 및 발표의 페이지별 제목·본문·사진 등 가능한 데이터를 **개별 요소로 변환**합니다. 원본 레이아웃의 모든 세부 장식과 타이포그래피가 완전히 동일하다는 보장은 없습니다. 원본을 덮어쓰지 않고 별도의 신규 프로젝트 ID로 저장합니다.

## 아직 통합하지 않은 기능

- 영상 타임라인/애니메이션, 음악 파형·트랙의 실시간 편집
- 문서의 정교한 서식·표, 공식 FilmCraft/SoundCraft 전문 편집 기능
- 모든 요소의 고급 회전·마스크·그룹 편집
- 통합 페이지 전체를 PPTX로 직접 변환하는 기능
- 아이폰/아이패드 Safari 실기기 화면·파일 출력 검수

**발표/영상 전달**은 당분간 PNG 장면 기준이라 원본 글씨가 다른 제작실에서 다시 편집 가능한 상태로 전달되는 것은 아닙니다. 앞으로 단일 프로젝트의 재생/출력 계층을 확장하는 3.1~3.2에서 해결해야 합니다.

## 기술 구조

- `studio-unified-core.js`: 프로젝트 데이터 형식 `gulliver.unified.canvas.v1`, 검증 및 레거시 도안/발표 변환
- `통합 캔버스.html` / `studio-unified-editor.js`: 독립 실행 가능한 단일 DOM 편집기. 사용자가 기존 제작실 UI에서 열면 동일한 편집 화면 안에 삽입
- `studio-core.js`: 여덟 번째 작업 종류 `canvas`를 자동 저장 대상으로 등록
- `studio-app.js`: 기존 항목의 **통합에서 편집** 복사 변환 및 캔버스 저장·내보내기 연결
- `studio-transfer-core.js`: 통합 캔버스에서 기존 도안/문서/PDF/영상으로 현재 페이지 이미지를 전달
- `tests/studio-unified-core.test.cjs`, `tests/studio-v30.e2e.cjs`: 유효성, 직접 편집·자동 저장·PNG 출력·원본 보존 브라우저 테스트

## 후속 구현

3.1의 후보는 이미지로 굳히지 않고 동일한 페이지 요소와 애니메이션의 실행 시간을 저장하는 타임라인, 화면 순서대로 발표/영상 재생하는 플레이어, 이후 공유 내보내기(3.2)입니다. 이를 위해 3.0은 기존 작업을 변경하지 않고 새 공통 요소 모델을 만드는 데 집중합니다.
