# 2026-10-25 클라시트 과학 5학년 1학기 전 차시 보강
기준: 2022 개정 미래엔 과학 공개 목차 · 코드의 실제 차시 연결과 출제 수용량

## 이번 변경 사항
- 학습 내용: 5학년 1학기 26개 차시. 변경 전에는 20문항을 만들 수 있는 차시 0개, 16개 차시가 아예 연결되지 않았다.
- 변경 후: **26/26차시** 모두 25문항 출제 가능. 새로 작성한 독립 130개 관찰 상황에 각 5문항을 연결해 **총 650개 문항**을 추가했다.
- 새 표 26개를 만들었다. 절벽 지층·퇴적암 입자·화석 단서·빛의 이동·용해 전후 질량·물의 온도와 용해량·진하기 비교·혈액과 오줌 이동 경로 등 4개 단원의 실제 학습목표별 자료이다.
- 지층과 화석: 6차시 × 25문항 = 150문항
- 빛의 성질: 5차시 × 25문항 = 125문항
- 용해와 용액: 7차시 × 25문항 = 175문항
- 우리 몸의 구조와 기능: 8차시 × 25문항 = 200문항
- 원래 과학·사회·국어 데이터는 삭제하지 않았다.

## 문항 구성 원칙
- 한 차시에서 5가지 **별개의 관찰·실험 상황**을 제시한다.
- 자료를 직접 읽어 답하는 사실 확인, 과학적 해석, 실험 조건·근거, 확인할 수 없는 정보의 구별, 후속 탐구를 각각 묻는다.
- 과학적 원리를 지나치게 단정하는 문장을 피한다. 다른 물질에도 항상 같은 용해 경향을 가정하거나 이슬·빛·인체에 관한 실제로 관찰하지 않은 것을 사실인 듯 추정하지 않는다.
- 용해량과 진하기는 동일한 용질·용매와 온도·질량 조건을 구별한다. 임의 수치를 사용한 경우 자료에 **가상**임을 표시한다.
- 오답 선지는 같은 차시의 다른 관찰 기록과 비교할 수 있게 만들었다. 다만 근거 자료의 반복 표현과 자연스러움은 추가 수업 검토가 도움이 된다.
- 표는 그 차시의 출제 시 하나 이상 포함되도록 각 문제은행에 연결했다.

## 실제 생성 검증
- 26차시 × 객관식/단답형/서술형 × 시드 7/42/101 = **234개 20문항 문제지 생성 성공**
- 20문항 모두 중복 없는 질문·자료, 정답·설명·선택지 무결성 검사 오류 0개.
- 26개 전 차시에서 시드별 문항 선택 다양성 검증.
- 객관식 78개 문제지 전부에 적어도 하나의 표가 들어간다는 점을 확인.
- `tests/worksheet-science-term1.test.cjs`에 고정된 테스트를 추가하고 GitHub CI 품질 게이트에서도 실행한다.
