# 사이트 버전 표시

공통 탑바 우측의 `v1.2.1`은 현재 페이지에서 불러온 공통 화면의 릴리스 번호입니다. 누르면 해당 릴리스의 날짜와 최근 변경 내용을 확인합니다. 학생용 표시, 삽입 화면, 인쇄에는 교사 탑바와 함께 숨겨집니다.

릴리스 시 `package.json`의 version과 `gulliver-app-shell.js`의 release.version을 함께 갱신합니다. release.date와 changes도 해당 릴리스에 맞게 작성하고, 공통 스크립트와 스타일을 연결한 HTML의 쿼리 버전을 갱신합니다. 이 값은 접속 시각이나 GitHub main의 최신 번호를 실시간으로 표시하는 것이 아니며, 운영 배포가 아직 반영되지 않은 브라우저 화면이 최신인 것처럼 보이지 않게 합니다.

릴리스 번호는 화면에 포함된 고정 값입니다. 모든 커밋이나 배포마다 자동 증가하지 않습니다.
