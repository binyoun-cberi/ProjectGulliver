# 한자·사자성어 따라쓰기

문제지 메뉴의 ‘한자·사자성어’에서 사용할 수 있습니다.

- 한자 250자: 대한검정회 8급 30자, 7급 누적 50자, 6급 누적 70자, 준5급 누적 100자, 5급 누적 250자. 선택한 급수에는 이전 급수의 한자가 포함됩니다.
- 사자성어·네 글자 표현 40개: 전체 40개, 기초 20개, 확장 10개, 심화 10개에서 선택합니다.
- 한자는 학년 대신 급수, 사자성어는 표현 범위로 선택합니다. 사자성어 분류는 공식 시험 급수와 대응하지 않습니다.
- 배정 근거: 대한검정회 2026-07-29 ‘등급별 선정한자(8급~사범)’ 공식 배정표. https://www.hanja.ne.kr/board/board/content.asp?tb=inno_12&page=1&num=15&gisacode=
- 한국어문회 등 다른 기관의 같은 급수와 배정 범위가 다르므로 UI와 문제지 제목에 대한검정회 기준을 표시합니다.
- 낱글자의 훈·음은 대표 표기입니다. 女(녀), 年(년), 力(력) 등은 낱말 안에서 두음법칙 등에 따라 다르게 읽을 수 있습니다.
- 한자: 큰 본보기, 훈·음, 십자 보조선, 흐린 글씨 3칸, 혼자 쓰기 2칸.
- 사자성어: 글자별 본보기와 훈·음, 뜻풀이, 예문, 네 칸씩 따라쓰기 2줄과 혼자 쓰기 1줄.
- ‘본보기 보고 혼자 쓰기’에서는 연습칸의 흐린 글씨를 모두 뺍니다.
- 5·10·15·20개, 큰 글씨, A4 자동 분할, 번호·URL을 통한 동일 문제지 재생성 지원.
- 획순 정보는 포함하지 않습니다. 확인되지 않은 획순을 임의로 표시하지 않습니다.

## 글꼴

`assets/fonts/hanja-tracing.otf`는 Noto Serif CJK KR Regular에서 사용되는 한자만 추린 ‘Clasheet Hanja Practice’입니다. 본보기와 흐린 글씨에 같은 글꼴을 사용합니다. 외부 글꼴 서버를 호출하지 않습니다.

- 원본: https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/Korean/NotoSerifCJKkr-Regular.otf
- 라이선스: SIL Open Font License 1.1 (`assets/fonts/NotoSerifCJK-OFL.txt`)
- 재생성 시 `worksheet-hanja.js`의 모든 character/characters를 모아 fontTools.subset을 실행하고 서브셋의 family/name을 Clasheet Hanja Practice로 지정합니다. 새 한자를 추가하면 반드시 글꼴도 갱신합니다.

## 검증

- 생성 검증: 모든 급수, 두 종류, 두 연습 방법, 네 가지 문항 수에서 중복·누락·범위·같은 번호 재현 검사.
- 브라우저: Chromium에서 5·10·15·20개 및 큰 글씨 A4 분할, 실제 PDF 쪽수, 페이지 밖 연습칸, 재접속, 과목 전환, 390px 화면 검사.
- 글꼴: 전체 한자가 서브셋 cmap에 모두 있는지 확인.
- 전체 기존 검사에서 나타나는 6건 실패는 수정 전 main(0d377a4)에서도 동일함을 별도 작업 디렉터리에서 확인. 미디어 브라우저 실행 환경 1건, 세로셈 소스 문자열 계약 1건, 사회 문제은행의 고정 개수·내용 단정 4건이며 이번 변경의 회귀가 아닙니다.
