# 역사 사진 관찰 문제

- 대상: 사회 5·6학년 → 역사 · 사진 관찰 → 사진과 설명으로 이름 찾기.
- 실제 국가유산청 사진 28종 중 5·10·15·20문항을 뽑는다. 사진만으로 식별이 어려운 기록물은 짧은 설명을 함께 제시한다.
- 같은 문제지에서 같은 사진과 정답을 중복하지 않는다. 보기와 문항 순서는 문제지 번호로 재현한다.
- 국가유산청 출처·공공누리 제1유형·크기 조정 사실과 원본 링크를 학생용 지면에도 표시한다. 이미지 파일명과 대체 텍스트에는 정답을 넣지 않는다.
- 외부 기관의 이미지 요청 없이 저장된 사진을 사용하며, 사진을 불러오지 못하면 인쇄를 중단한다.
- 사진 57장을 확보했지만 28장만 이번 유형에 사용한다. 자격루의 받침, 환구단의 천장, 추가 9장의 부재·내부·옛 사진은 유산 전체 이름을 사진으로 식별시키기에 부적합해 현재 출제하지 않는다.
- 출처·기존 권리 확인 기록은 data/history-heritage-rights.json, 추가 파일의 확인 기록은 data/history-heritage-candidates.json에 보관한다. 지면에 연결한 사진은 data/history-photo-bank.js에서 확인한다.

검사: 두 학년, 5·10·15·20문항, 여러 시드의 사진·정답 중복과 파일 존재 및 출처 메타데이터를 확인한다. Chrome 없는 환경에서는 실제 A4 페이지 배치 검사는 실행하지 못했다.
