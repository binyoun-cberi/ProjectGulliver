# 모바일 국어 말하기 · 영어 스피킹

## 교사와 학생의 흐름

교사는 국어/영어, 기초 단어·짧은 표현/학년별 문장/직접 입력, 5·10·15·20문제, 생성 후 24시간/일주일을 선택한다. 과제를 먼저 확인하고 QR 또는 주소를 공유한다. 학생들은 같은 주소를 열어도 각자 탭에서 독립적으로 진행한다. 기초 단어·표현은 언어별 40개이고 문장은 기존 국어 1~6학년·영어 3~6학년 은행을 사용한다.

학생이 연습 시작을 누르면 회색 어절·단어와 파란 마이크가 보인다. 마이크를 직접 눌렀을 때만 SpeechRecognition/webkitSpeechRecognition을 시작한다. 국어는 ko-KR, 영어는 en-US를 지정한다. 인식된 내용과 일치하는 어절·단어를 초록색 밑줄로 표시한다. 밑줄과 상태 안내도 있어 색만으로 구분하지 않는다. 부분 인식은 실시간으로 보여 주되 모든 항목의 최종 인식이 확인되면 650ms 동안 초록색을 보여 준 뒤 자동으로 다음 문제로 넘어간다. 직접 누르는 ‘다음 문제’는 미응답도 넘길 수 있으며 넘긴 문제로 집계한다. 임시 인식이 수정되면 색도 되돌아간다.

일치는 문장 부호·대소문자·유니코드 정규화를 적용한 뒤 순서와 중복 위치를 고려하여 비교한다. 한 번 말한 단어가 같은 단어 여러 개를 동시에 충족시키지 않는다. 이것은 음성 인식 결과의 텍스트 일치 확인이며 정밀한 발음·유창성 평가는 아니다. 띄어쓰기, 숫자 표현, 축약형과 인식 오류 때문에 맞게 읽어도 회색으로 남을 수 있다. 다시 말하거나 ‘다음 문제’를 선택한다.

마이크 다시 누르기, 다음 문제, 쉬기, 페이지 이탈, 화면 숨김, 만료 시 인식을 중단한다. 중단된 이전 문제의 콜백은 무시한다. 권한 거부·마이크 없음·네트워크·말소리 없음·브라우저 미지원에는 안내를 표시하며 지원하지 않는 환경을 정상 채점처럼 처리하지 않는다. 기기별 실제 인식 정확도와 권한 경험은 별도 확인 대상이다.

## 저장과 공유

녹음 파일·MediaRecorder·음성 업로드 API를 구현하지 않는다. 음성 파일이나 인식문을 클라시트 저장소에 저장하지 않는다. 브라우저의 인식 엔진이 음성을 외부 서비스로 전달할 수 있다는 점을 학생 시작 화면에 알린다. 참고: https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition . 오프라인 동작이나 음성이 기기 밖으로 나가지 않는다고 보장하지 않는다.

탭의 sessionStorage에는 문제 순서·현재 위치·재연습 항목·완료 상태만 저장한다. 새로고침 후 현재 문제의 음성 확인은 다시 한다. 탭 종료·저장 제한 환경에서는 진행이 사라질 수 있다. 교사에게 결과를 전송하지 않으며 계정·학급 집계·실시간 교사 대시보드는 포함하지 않는다.

기존 로컬 QR 생성기를 사용한다. 문장 주소에는 선택된 문장 ID를 넣어 은행이 커져도 같은 문장을 연다. 직접 입력은 한 줄 120자·전체 1,600자로 제한하고 URL fragment에 담으며 textContent로 표시한다. 주소를 가진 학생에게 공개되는 내용이므로 개인정보를 넣지 않는다. QR 용량 초과 시 입력을 줄이거나 주소 공유를 안내한다. file 주소에서는 휴대폰용 QR을 만들지 않는다.

## 유효기간의 범위

QR과 직접 공유 주소 모두 issued/expires를 포함하며 생성 시점으로부터 정확히 24시간 또는 7일 후 만료한다. 누락·잘못된 기간·과도하게 미래인 발급 시각은 거부한다. 만료 경계에서 신규 입장뿐 아니라 진행 중 화면도 잠그고 마이크를 중단한다. 매초 및 시작·마이크·문제 전환·재개 시 확인한다. 교사·학생 화면에 만료 시각을 보여 준다.

현재 정적 사이트의 클라이언트 시간 검사이다. 서버 서명·서버 시각 검증·QR 폐기 DB가 없으므로 주소 매개변수 또는 기기 시간을 고의로 바꾸는 것을 막는 보안 만료는 아니다. 엄격한 접근 제어가 필요하면 서버 발급·서명 검증을 추가해야 한다. 아직 배포하지 않은 초기 PR의 기간 없는 학생 URL은 새 QR로 다시 만들어야 한다.

## 검증

단위·DOM 검사 5개에서 두 언어·세 유형·네 문제 수, 고유 문제·문장 ID 복원, QR 생성·기간 선택, 학생 독립 진행, 새로고침·쉬기·완료·복습, 안전한 텍스트 표시, 인식 전 다음 버튼 차단, 임시 색 되돌림·최종 확인, 오래된 이벤트 무시, 권한 거부·미지원, 만료 경계를 확인한다.

실제 Chromium 검사에서는 HTTPS 경로를 재현해 QR 생성과 두 모바일 탭의 독립 진행, 390px 폭, 새로고침, 마이크 버튼·텍스트 색·완료·재연습을 확인한다. 이 검사의 음성 인식 이벤트는 모의 엔진을 사용한다. 실제 학생 음성·휴대폰 마이크와 인식 정확도, 실기기 QR 카메라 촬영을 검증한 것은 아니다.


## 자동 진행과 결과 집계

정답 확인 중에는 마이크를 중단하고 다음 버튼을 잠시 막아 정답이 넘긴 문제로 중복 집계되지 않게 한다. 다음·쉬기·화면 숨김·만료는 예약된 자동 진행을 취소하며, 이전 인식 콜백이 다음 문제를 넘기지 못한다. 마이크는 다음 문제에서 다시 누른다.

맞힌 수는 이번 회차에서 진행한 문제 수에서 넘긴 수를 뺀 값이다. 마지막에는 ‘3 / 5’와 ‘넘긴 문제 2개’를 별도 표시한다. 넘긴 문제만 다시 연습하면 ‘다시 연습 결과’로 해당 회차의 수를 표시한다. 전체 재시작은 새 회차로 집계한다. 저장된 진행과 넘긴 목록에서 결과를 복원한다. 임시 인식·인식 실패·미지원 상태에서 다음을 눌러도 정답으로 더하지 않는다.

홈의 말하기 영역에 국어 말하기·영어 스피킹 카드를 각각 제공하고 각 언어가 미리 선택된 교사 화면으로 이동한다. 검색과 과목 메뉴에서도 개별 진입한다. 학생 안내는 ‘다 맞히면 다음으로’, ‘다음 문제’, ‘연습 결과’ 등으로 간결하게 다듬었으며 음성 사용 안내는 펼쳐 볼 수 있게 했다.

자동 진행 변경 검사는 단위·DOM 7개로 중복 콜백, 임시 결과, 자동 전환 취소, 혼합 정답·넘김의 정확한 집계, 0점, 복습, 만료와 언어별 진입을 확인한다. 별도 Chromium 학생 화면 검사 1개와 홈 탐색 회귀 검사 1개도 통과했다. 합계 9개 검사 통과. 320·390·768·1024·1920px 홈 화면 가로 넘침과 국어·영어 별도 카드를 확인하고 화면 이미지를 열어 확인했다. 음성 인식 이벤트는 모의 입력이며 실제 휴대폰 음질 검사는 아니다.


## 학생 연습 화면 배치와 들린 말풍선

참고 이미지의 흐름을 따라 흰 배경, 위쪽 진행 막대와 쉬기 버튼, 큰 제시 문장 말풍선, 파란 ‘탭하여 말하기’, 들린 말풍선, 아래쪽 ‘지금 말할 수 없어요’ 순으로 배치했다. 캐릭터는 넣지 않았다. 마지막 버튼은 수동 넘기기이며 기존 넘긴 수 집계·재연습에 연결한다. 연습 중에는 준비 안내를 숨겨 과제와 말하기에 집중하도록 한다.

‘이렇게 들었어요’ 말풍선에는 현재 마이크 차례의 최종·임시 인식문을 그대로 보여 준다. 이전 마이크에서 누적된 채점용 텍스트와 구분한다. 새 문제·다시 시작·복습 문제로 이동하면 지우고, 중단된 이전 문제의 콜백은 화면을 바꾸지 못한다. textContent로 표시하며 인식문을 저장하거나 교사에게 전송하지 않는다. 녹음 파일도 만들지 않는다.

추가 검증: 단위·DOM 7개 및 실제 Chromium 1개 통과. 부분 인식 말풍선 표시·수정·새 문제 초기화·오래된 이벤트 무시·HTML 문자열의 안전한 표시와 마이크→말풍선→넘기기의 세로 순서를 확인했다. 390px 모바일 화면을 이미지로 열어 배치와 한글 표시를 검토했다. 앞선 홈 회귀 1개도 통과했으며 홈 코드는 이번 레이아웃 수정에서 변경하지 않았다. 인식 이벤트는 모의 입력이다.
