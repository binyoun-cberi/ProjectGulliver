# 모바일 국어 말하기 · 영어 스피킹

## 범위

교사가 언어, 기초 단어/짧은 표현·학년별 문장·직접 입력, 5·10·15·20문제를 선택한다. 생성된 과제를 먼저 확인하고 학생용 URL과 QR을 공유한다. 학생들은 같은 QR로 각자 접속하되 진행 상태는 기기의 해당 탭에 따로 저장한다. 교사 화면에 학생 기록은 전송되지 않는다.

학생은 시작을 누르고 한 항목씩 크게 보며 소리 내어 읽는다. ‘말했어요’ 또는 ‘다시 연습할래요’를 선택해 다음으로 진행한다. 잠시 쉬기, 새로고침 후 이어하기, 완료 화면, 어려웠던 항목만 재연습, 전체 재시작을 제공한다. 영어 항목에는 영어 언어 속성을 지정한다. 숨겨진 교사 설정 화면과 별도로 학생 화면을 구성했다.

이 버전은 보고 읽는 연습이다. 실제 말했는지·발음·유창성을 자동 판정하지 않고 마이크·녹음·음성 업로드도 사용하지 않는다. 완료는 학생의 자기 확인이다. 시간 압박이나 발음 점수를 도입하려면 별도 설계가 필요하다.

## 데이터와 공유

기초 단어·짧은 표현 40개씩을 국어와 영어로 제공한다. 문장은 기존 국어 1~6학년·영어 3~6학년 은행을 재사용한다. 같은 시드로 같은 과제가 생성되고 학생마다 진행만 독립된다. 문장 과제 주소에는 선택된 문장 ID를 넣어 이후 은행이 확장되어도 선택한 문장을 복원한다. 직접 입력은 중복 없이 문제 수 이상, 한 줄 120자·전체 1,600자까지이며 주소의 fragment에 넣는다. fragment 내용도 주소를 받은 학생이 볼 수 있으므로 개인정보를 넣지 않는다.

기존 로컬 QR 생성기를 사용하며 외부 QR 서비스로 과제 주소를 보내지 않는다. HTTPS/HTTP 주소에서 QR을 만든다. 입력이 길어 QR 생성에 실패하면 입력을 줄이거나 주소를 공유하도록 안내한다. file URL은 휴대폰에서 접근할 수 없으므로 QR을 표시하지 않는다. 과제 공유에는 실제 배포 주소를 사용한다.

진행은 sessionStorage에 저장한다. 탭을 닫거나 저장이 제한된 환경에서는 사라질 수 있다. 학생 이름·인증·학급 집계·교사 실시간 대시보드는 이번 범위에 포함하지 않는다. 직접 입력은 textContent로 표시한다. 잘못된 과제 주소와 손상된 진행 기록은 검증한다.

## 검증

단위·DOM 검사로 두 언어·세 과제 유형·네 문제 수의 정확한 생성, 중복 방지, 주소 재현, 잘못된 입력, 교사용 QR 생성, 두 학생의 독립 진행, 중단·재개·완료·재연습, 저장 복원과 HTML 문자열의 안전한 표시를 검사했다. 기존 받침·받아쓰기 DOM 회귀를 함께 실행했다. 별도 Chromium 검사에서 모바일 폭 390px, 두 학생 탭, 영어 문장 5문제, 새로고침 복원, 쉬기·이어하기·완료·재연습을 확인했다. 단위·DOM 회귀 4개와 브라우저 1개가 통과했다. 자동 음성 평가의 정확성을 검사했다고 주장하지 않는다.
