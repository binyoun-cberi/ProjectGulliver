# 국어·영어 직접 입력 받아쓰기

받아쓰기의 ‘문장 고르기’에서 문제 은행과 직접 입력을 선택한다. 직접 입력은 한 줄에 한 문장씩 1~10문장, 문장마다 최대 120자이며 빈 줄과 앞뒤 공백만 제거한다. 대문자·문장 부호·문장 안의 띄어쓰기와 입력 순서를 유지한다. 의도적인 반복 문장도 허용한다. 입력 내용은 HTML로 해석하지 않는다.

‘입력한 문장으로 문제지 만들기’를 누르면 현재 언어와 학년으로 문제지를 만든다. 직접 입력에서는 두 언어 모두 1~6학년을 선택할 수 있다. 기존 영어 문제 은행은 3~6학년 범위를 유지한다. 학년을 바꾸어도 직접 입력한 문장의 난도나 문구를 자동으로 바꾸지 않는다.

기존 TTS 플레이어를 사용하므로 언어별 음성, 문장별 1~3회 읽기, 반복 사이 간격, 다음 문장까지 쓰는 시간, 일시정지·다시 읽기를 그대로 쓴다. 실제 문장 수에 따라 진행 표시·완료 안내·문제지 제목·학생용 인쇄 버튼을 표시한다. 문장 내용을 편집하거나 언어·입력 방식을 바꾸면 기존 음성을 멈춘다. 편집 중에는 이전 문제와 정답을 비우고, 새 문제지를 만들기 전까지 시작·인쇄를 비활성화한다.

## 저장과 복원

국어·영어 초안은 `clasheet-dictation-custom-drafts.v1`에 각각 저장한다. 적용한 문제지는 `clasheet-dictation-custom-sheets.v1`에 독립 ID로 저장하며, 설정 변경과 다시 열기는 같은 ID를 사용한다. 문장 원문 대신 ID를 문제지 주소에 넣는다. 같은 브라우저의 같은 사이트에서 주소를 다시 열면 문장·순서·학년·읽기 설정을 복원한다. 이 저장 방식은 다른 기기나 브라우저로 문장 내용을 전달하는 공유 기능은 아니다.

저장 기록이 없거나 손상된 직접 입력 주소는 새 은행 문제로 대체하지 않고 문장을 입력하도록 안내한다. 브라우저 저장 실패 시 현재 문제지는 사용할 수 있고, 새로고침 전 문장을 따로 보관하라는 안내를 보여 준다. 기존 문제 은행의 문항 ID·시드 주소와 읽기 설정 저장 키를 유지한다.

## 인쇄와 검증

학생용은 답을 숨기고 쓰기 줄만 표시하며, 교사용은 입력한 문장 그대로 표시한다. 직접 입력 문장의 교사용 글자 크기와 줄 간격을 조절하여 최대 길이의 10문장도 A4 한 장의 각 문항 안에 들어가도록 한다. 입력창과 읽기 설정은 인쇄하지 않는다.

완료 기준: 국어·영어 입력·순서·음성 언어·진행 수·주소 복원·편집 시 음성 중단·학생/교사용 인쇄가 동작하고 기존 은행 흐름이 유지되어야 한다.

테스트 실행 명령:

`node --test tests/worksheet-dictation-custom.test.cjs tests/worksheet-dictation-dom.test.cjs tests/worksheet-dictation.test.cjs tests/worksheet-english-dictation.test.cjs` (`WORKSHEET_JSDOM` 설정): 입력 경계, 문장 부호·반복 보존, HTML 이스케이프, 언어별 초안, 저장 주소 복원, 없는 주소, 편집·언어 변경 시 중단과 취소된 콜백, 기존 3회 반복·간격 동작을 검사한다.

`node --test tests/worksheet-dictation-custom-browser.test.cjs tests/worksheet-dictation-browser.test.cjs` (`CHROME_BIN`, `NODE_PATH` 등 로컬 Chrome 환경 설정): 두 언어의 직접 입력과 기존 은행 흐름, 언어·문장 전달, 390px 모바일, 학생용 정답 숨김, 최대 길이 10문장의 학생/교사용 PDF 각 1쪽과 답의 행 내부 배치를 검사한다. 브라우저 TTS는 모의 음성 인터페이스로 호출과 언어 전달을 확인하며 실제 음질을 평가하지 않는다.
