# 뚝딱 제작실 2.3 — FilmCraft·SoundCraft 고급 프로젝트 보관

## 사용 방법

### FilmCraft 영상 고급 편집
1. 뚝딱 제작실 → 영상 뚝딱 → **고급 편집 · FilmCraft**에서 편집합니다.
2. 영상 화면의 **현재 FilmCraft 프로젝트 → 내 작업 보관**을 누릅니다. FilmCraft 자체 `file.saveAs/readFile` API로 얻은 원본 `.fcproj` 사본을 브라우저 IndexedDB에 보관합니다.
3. 오른쪽 **내 작업 → 고급 편집기 원본**에서 열기, 이름 수정, 폴더 이동, 내려받기, 삭제를 사용할 수 있습니다.
4. **열기**는 FilmCraft 고급 편집기를 띄운 뒤 해당 사본을 `openProject(File)`에 전달합니다. 연결된 원본 영상·사진은 `.fcproj`에 포함되지 않을 수 있으므로 별도로 백업하세요.

### SoundCraft 음악 고급 편집
1. SoundCraft 안에서 **Ctrl+S / 공식 저장 기능**으로 `.scraftz` 세션 원본을 내려받습니다.
2. 고급 편집 화면의 **공식 프로젝트 파일 보관** 또는 **내 작업 → + 공식 프로젝트 파일 보관**에서 그 파일을 선택합니다.
3. **내 작업 → 열기**를 누르면 저장해 둔 `.scraftz`를 원본 SoundCraft의 웹 캔버스에 파일 드롭 방식으로 전달합니다.
4. 프로그램 화면에서 트랙과 오디오가 실제로 잘 복원되었는지 직접 확인하세요. 이 경로는 원본 프로그램의 로더를 활용하며, 내부 세션 데이터 정확성을 완전히 분석하거나 보증하지 않습니다.

## 데이터·안전 규칙

- 기존 IndexedDB `gulliver-studio-v1`의 schema version을 **4**로 올리고 `official` 전용 저장소를 추가합니다. 저장소 이름은 이전과 같아 기존 작업을 유지합니다.
- 개별 공식 원본: 최대 **95MiB**, 총 **30개**. 이름 확장자와 JSON/ZIP 시그니처를 모두 검사합니다.
- 브라우저 자동 저장은 **간편 제작실**에만 해당합니다. 공식 프로그램의 편집 상태는 **보관 버튼을 누르거나 저장한 프로젝트 파일을 다시 가져올 때만** 새 스냅샷이 생깁니다.
- `내 작업`에서 여는 공식 프로젝트는 같은 편집기 화면을 사용하지만 **새 간편 작업을 생성하지 않습니다.**
- 전체 백업(`gulliver.studio.bundle`, version 1)에는 기존의 간편 작업, 이미지, 영상/음원 소재, 폴더, 내 활동에 더해 공식 원본도 base64로 포함됩니다. 옛 version 1 파일에는 `official` 키가 없어도 복원됩니다.
- 120MiB JSON 한도를 초과할 것으로 보이면 **사전에 백업을 거부**하고 개별 공식 파일 다운로드를 안내합니다. 고급 원본을 자동으로 누락한 “전체 백업”을 성공으로 표시하지 않습니다.
- 백업 복원에서 공식 파일과 기존 간편 프로젝트·소재·폴더는 하나의 IndexedDB 트랜잭션으로 추가됩니다. 동일 ID의 기존 항목을 덮어쓰지 않도록 새 ID를 부여합니다.
- 기기·브라우저 간 원본은 자동 동기화되지 않습니다. Safari의 저장 공간 제한이나 파일 크기에 따라 보관에 실패할 수 있으니 파일을 개별 내려받아 보관하세요.

## 자동 검수

- `tests/studio-official-library.test.cjs`: 타입/형식/용량, 뒤로 호환되는 백업, 프로젝트 분리.
- `tests/studio-official-library.e2e.cjs`: 브라우저에서 원본 가져오기·폴더 이동·다운로드·백업·복원·열기·간편 프로젝트 유령 생성 방지. 이 테스트의 작은 ZIP/JSON은 보관함 기능을 점검하는 **합성 파일**로 실제 SoundCraft 유효 세션의 완전 복구 테스트가 아닙니다.
- `tests/studio-official-workflows.e2e.cjs`: 공식 원본 WASM으로 FilmCraft의 실제 파일 저장→보관→재접속→`.fcproj` 다시 열기 및 실제 SoundCraft `.scraftz` 세션 보관. 두 편집기의 전체 장시간 영상/녹음 워크플로는 범위 밖입니다.
