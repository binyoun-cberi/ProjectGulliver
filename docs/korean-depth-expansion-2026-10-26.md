# 국어 문제은행 보강 검토 (2026-10-26)

## 범위와 완료 기준

과학 PR #158 병합 후 국어 읽기 차시의 문항 부족을 보완한다. 새 창작 지문 22편(시 8편, 이야기 8편, 설명문 6편)에 각 5문항을 붙이고, 중심 내용 및 사실·의견 자료형 문항을 각각 20개 추가했다. 합계 150문항이며 정답, 오답 선택지, 해설을 포함한다. 외부 작품이나 교과서 지문을 복제하지 않았다.

기존 지문과 문항 ID 순서를 보존하고 확장 모듈을 뒤에 등록한다. 고학년 지문을 저학년 차시에 섞지 않으며, 시 비유 차시에는 시의 비유 문항만 제공한다. 자료형 문항은 문단 중심 내용 필터에도 명시적으로 포함한다.

## 위험과 판정

문항 수를 늘리려고 목표와 다른 일반 독해 문항을 비유 차시에 섞으면 범위가 부풀려질 수 있다. 이에 새 시·이야기의 비유 문항을 각각 두 개씩 작성하고 기존 장르·기능 필터를 유지했다. 추가 지문은 창작 텍스트이므로 실제 교과서 본문과 일치한다고 주장하지 않는다. 정답은 제시된 지문에서 판단하도록 구성했다.

자료 구조와 UI 검증 결과를 근거로 리뷰 요청 가능으로 판정한다. 문학 해석 표현과 학년별 어휘 난도는 사람의 추가 편집 검토 대상으로 남긴다.
