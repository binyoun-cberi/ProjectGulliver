# 매일 수업 문제지 · 2022 개정 성취기준 대조

기준 문서: 교육부 고시 제2022-33호의 별책 5(국어), 7(사회), 8(수학), 9(과학), 14(영어). 수학은 [국가교육과정정보센터 원문](https://ncic.re.kr/inv/org/download.do?orgType=ogi4&seq=10003559&year=2022)을, 다른 교과는 각 표의 교육청 자료에 실린 성취기준을 대조했다. 학년군의 성취기준을 출판사별 학기·교과서 단원 번호로 단정하지 않는다.

| 1~2 | 덧셈과 뺄셈 | [2수01-06] | 1학년은 10 또는 20 이내, 2학년은 두 자리 수 이내 계산. 실생활 의미나 계산 원리 설명까지 평가하지 않음 |
| 2 | 곱셈 | [2수01-11] | 곱셈구구 계산. 구체물로 곱셈 뜻을 설명하는 활동은 없음 |
| 3~4 | 덧셈과 뺄셈 | [4수01-03] | 세 자리 수의 계산만 출제. 계산 원리를 설명하는 문항은 없음 |
| 3 | 세 자리 수 덧셈 A/B | [4수01-03] | 받아올림 없는 계산의 반복 연습만 제공 |
| 3~4 | 곱셈 | [4수01-04] | 곱하는 수가 한두 자리인 계산. 계산 원리 설명은 없음 |

성취기준 코드를 붙인 문제지도 해당 기준 전체를 평가했다는 뜻이 아니다. 인쇄물에는 유형별로 실제 출제한 범위만 표시한다.

사회 ‘방향과 위치’는 가상의 3×3 위치도를 읽는 선행 연습이다. [4사01-02]의 디지털 영상 지도·고장 주요 지형지물 파악과 동일하다고 볼 수 없으므로 코드를 붙이지 않는다. [경기도교육청 지역 연계 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202501150432222811.pdf)를 참고해 실제 지역 자료를 사용하는 유형을 별도로 설계해야 한다.

## 대조 중인 유형

| 교과 | 현재 유형 | 다음 대조 작업 |
| --- | --- | --- |
| 국어 | 반대말, 띄어쓰기, 글 읽고 답하기 | 기존 상세 정보 찾기를 중심 내용 파악과 혼동하지 않고, 학년군별 어휘·문법·읽기 기준을 구분 |
| 수학 | 수의 자리와 크기, 시각과 시간, 분수, 5~6학년 계산 | 학년군별 수 범위와 분수 연산의 범위를 원문과 대조한 뒤 세부 유형 분리 |
| 사회 | 방향과 위치, 우리 사회의 일, 5~6학년 생산과 소비 | 자료·지도 읽기와 실제 지역·사회 사례를 구분하고 근거 자료를 명시 |
| 과학 | 생물과 비생물, 5~6학년 물질의 상태 | 관찰·분류·탐구 과정을 묻는 문항을 만들고 사실 암기형만으로 기준 전체를 표시하지 않기 |
| 영어 | 문장 만들기, 대답 고르기 | 듣기·말하기·읽기·쓰기 영역별 기준을 분리하고 텍스트만으로 듣기 기준을 표시하지 않기 |

현재 `data-standards.js`는 문제지의 근거 자료로 사용하지 않는다. 예를 들어 이 파일의 `[2수01-03]` 설명은 두 자리 수 덧셈으로 되어 있지만 원문에서 해당 계산 기준은 `[2수01-06]`이다. 기존 목록을 자동 매핑하면 잘못된 코드가 인쇄되므로 개별 원문 검증이 선행되어야 한다.

## 출제 순서

1. 원문의 학년군·영역·성취기준을 확인한다.
2. 그 기준에 해당하는 문항 생성 규칙의 수 범위와 응답 방식을 정한다.
3. 15/24문항을 서로 다르게 생성할 수 있는지 확인한다.
4. 문항의 정답과 난이도를 검수한 뒤 단원 선택기에 노출한다.
5. 실제 학교에서 사용하는 학기·교과서 단원명은 별도의 선택형 매핑으로 제공한다.
