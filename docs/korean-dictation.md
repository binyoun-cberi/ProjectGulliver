# 학년별 받아쓰기

국어 문제지의 ‘받아쓰기 · 음성 읽기’ 또는 상단 문제지 메뉴의 ‘국어 받아쓰기’에서 연다. 한 번에 10문장을 뽑으며, 시작 버튼을 누른 뒤에만 음성을 재생한다. 새 문장은 직전 10문장을 우선 제외한다. URL은 학년과 문장 ID를 저장하므로 같은 문제지를 다시 열 수 있다. 이때 음성은 자동으로 시작하지 않는다.

## 문장 수준

학년마다 직접 쓴 별도 문장 30개, 총 180문장이다. 교과서 급수나 공식 교육과정 평가 문장으로 표시하지 않는다.

| 학년 | 중점 |
| --- | --- |
| 1 | 익숙한 생활 어휘, 짧은 문장, 기본 받침과 띄어쓰기 |
| 2 | 다양한 받침과 소리 나는 말, 짧은 연결 문장 |
| 3 | 소리와 다른 표기, 겹받침과 문장 연결 |
| 4 | 꾸며 주는 말, 높임 표현, 연결되는 문장의 호응 |
| 5 | 긴 문장의 호응, 의존 명사, 맥락 속 어휘와 띄어쓰기 |
| 6 | 복합문, 추상 어휘와 논리적 관계, 정확한 표기 |

## 읽기 동작

기본은 천천히, 문장마다 세 번이다. 읽기 속도와 횟수(1~3번), 반복 사이의 쉼(기본 10초), 다음 문장까지 쓰는 시간(기본 20초)을 따로 정한다. 한 문장의 첫 읽기에만 번호를 읽으며, 문장 부호의 이름은 따로 읽지 않는다. 교사용 문장 확인에 이를 표시한다.

Web Speech API의 `SpeechSynthesisUtterance.onend` 뒤에 대기를 시작한다. 모든 문장을 한꺼번에 음성 큐에 넣지 않는다. 일시정지는 현재 음성을 취소하고 이어서 시작할 때 해당 회차의 문장을 처음부터 읽는다. 대기 중 일시정지는 남은 시간을 보존한다. 취소한 음성의 늦은 콜백은 실행 세대 번호로 무시한다. 학년 변경·새 문장·처음으로·문장 이동도 이전 음성과 타이머를 취소한다. 탭이 숨겨지거나 인쇄할 때는 일시정지하고 화면 종료 시에는 정지한다.

음성 목록은 `voiceschanged`로 갱신한다. 한국어 음성이 있으면 선택할 수 있고, 아직 목록이 없으면 `ko-KR` 기본 음성으로 시도한다. 한국어가 없는 음성 목록만 있거나 합성 API가 없으면 읽기를 비활성화하고 안내한다. 음성 오류나 45초 응답 지연은 중지 상태로 처리하여 문장을 건너뛰지 않는다. 오류 후 다시 시작할 수 있다. 기기의 한국어 음성에 따라 실제 발음과 속도는 달라진다.

학생용 화면·인쇄에는 답을 감추고, 교사용 확인을 펼칠 때만 문장을 보여 준다. 시작·다시 읽기·새 문장에서는 확인란을 닫는다. 학생용과 교사용은 각각 A4 한 장으로 인쇄한다. 음성 재생 중 설정은 잠그며, ‘처음으로’ 또는 새 문장/학년 선택 후 바꿀 수 있다. 읽기 설정은 브라우저에 저장하되 저장 불가 시에도 사용할 수 있다.

참고: [Web Speech API 규격](https://wicg.github.io/speech-api/).

## 검증

- 데이터/재생 단위 검사: 학년별 별도 문장, 난도 차이, 10문장 추첨·제외·저장 재현, 1~3회 반복, 음성 종료 후 정확한 대기, 일시정지·취소·이동·오류·미지원 환경.
- DOM 검사: 학년 변경, 정답 확인 닫기, 인쇄, 잘못된 저장 주소, 한국어 음성 없는 환경의 인쇄 기능.
- Chromium 검사: 실제 페이지의 음성 호출(테스트용 합성 객체), 버튼 동작, 저장 주소, 학생용 정답 숨김, 6개 학년 학생/교사용 PDF 12종의 A4 한 장·하단 넘침 없음, 390px 모바일과 국어 진입 링크.
- 헤드리스 환경은 실제 한국어 음성을 청취할 수 없어, 실제 음질과 iPhone/Safari 발음은 확인하지 않았다. 타이밍 검사는 합성 이벤트를 재현하여 수행한다.
