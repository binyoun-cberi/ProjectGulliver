# 학년별 받아쓰기

국어 문제지의 ‘받아쓰기 · 음성 읽기’ 또는 상단 문제지 메뉴의 ‘국어 받아쓰기’에서 연다. 한 번에 10문장을 뽑으며, 시작 버튼을 누른 뒤에만 음성을 재생한다. 새 문장은 직전 10문장을 우선 제외한다. URL은 학년과 문장 ID를 저장하므로 같은 문제지를 다시 열 수 있다. 이때 음성은 자동으로 시작하지 않는다.

## 문장 수준

직접 쓴 별도 문장 총 1,060개다. 1~4학년은 각각 210개, 5~6학년은 각각 110개다. 기본 30문장과 여덟 주제 각 10문장에, 1~4학년의 연습 급수 각 100문장을 추가했다. 교과서 급수나 공식 교육과정 평가 문장으로 표시하지 않는다.

| 학년 | 중점 |
| --- | --- |
| 1 | 익숙한 생활 어휘, 짧은 문장, 기본 받침과 띄어쓰기 |
| 2 | 다양한 받침과 소리 나는 말, 짧은 연결 문장 |
| 3 | 소리와 다른 표기, 겹받침과 문장 연결 |
| 4 | 꾸며 주는 말, 높임 표현, 연결되는 문장의 호응 |
| 5 | 긴 문장의 호응, 의존 명사, 맥락 속 어휘와 띄어쓰기 |
| 6 | 복합문, 추상 어휘와 논리적 관계, 정확한 표기 |

## 읽기 동작

기본은 천천히, 문장마다 세 번이다. 읽기 속도와 횟수(1~3번), 반복 사이의 쉼(기본 10초), 다음 문장까지 쓰는 시간(기본 20초)을 따로 정한다. 한 문장의 첫 읽기에만 번호를 읽으며, 문장 부호의 이름은 따로 읽지 않는다. 교사용 문장 확인에 이를 표시한다.

Web Speech API의 `SpeechSynthesisUtterance.onend` 뒤에 대기를 시작한다. 모든 문장을 한꺼번에 음성 큐에 넣지 않는다. 일시정지는 현재 음성을 취소하고 이어서 시작할 때 해당 회차의 문장을 처음부터 읽는다. 대기 중 일시정지는 남은 시간을 보존한다. 취소한 음성의 늦은 콜백은 실행 세대 번호로 무시한다. 학년 변경·새 문장·처음으로·문장 이동도 이전 음성과 타이머를 취소한다. 탭이 숨겨지거나 인쇄할 때는 일시정지하고 화면 종료 시에는 정지한다.

음성 목록은 `voiceschanged`로 갱신한다. 한국어 음성이 있으면 선택할 수 있고, 아직 목록이 없으면 `ko-KR` 기본 음성으로 시도한다. 한국어가 없는 음성 목록만 있거나 합성 API가 없으면 읽기를 비활성화하고 안내한다. 음성 오류나 45초 응답 지연은 중지 상태로 처리하여 문장을 건너뛰지 않는다. 오류 후 다시 시작할 수 있다. 기기의 한국어 음성에 따라 실제 발음과 속도는 달라진다.

학생용 화면·인쇄에는 답을 감추고, 교사용 확인을 펼칠 때만 문장을 보여 준다. 시작·다시 읽기·새 문장에서는 확인란을 닫는다. 학생용과 교사용은 각각 A4 한 장으로 인쇄한다. 음성 재생 중 설정은 잠그며, ‘처음으로’ 또는 새 문장/학년 선택 후 바꿀 수 있다. 읽기 설정은 브라우저에 저장하되 저장 불가 시에도 사용할 수 있다.

참고: [Web Speech API 규격](https://wicg.github.io/speech-api/).

## 검증

- 데이터/재생 단위 검사: 학년별 별도 문장, 난도 차이, 10문장 추첨·제외·저장 재현, 1~3회 반복, 음성 종료 후 정확한 대기, 일시정지·취소·이동·오류·미지원 환경.
- DOM 검사: 학년 변경, 정답 확인 닫기, 인쇄, 잘못된 저장 주소, 한국어 음성 없는 환경의 인쇄 기능.
- Chromium 검사: 실제 페이지의 음성 호출(테스트용 합성 객체), 버튼 동작, 저장 주소, 학생용 정답 숨김, 6개 학년 학생/교사용 PDF 12종의 A4 한 장·하단 넘침 없음, 390px 모바일과 국어 진입 링크.
- 헤드리스 환경은 실제 한국어 음성을 청취할 수 없어, 실제 음질과 iPhone/Safari 발음은 확인하지 않았다. 타이밍 검사는 합성 이벤트를 재현하여 수행한다.

## 첨부 자료를 참고한 주제 확장

사용자가 제공한 「차근차근 받아쓰기」 1학기 계기교육(54쪽), 2학기 계기교육(54쪽), 5~6학년 주제(29쪽)를 읽고, 주제별 열 항목·연습과 점검의 구성·계기교육과 생활 어휘의 결합을 참고했다. 계기교육 자료의 본문 글자는 추출되지 않아 주제 모음 페이지를 그림으로 확인했다. 업로드 원본은 저장소에 넣지 않는다.

추가 문장은 모두 새로 쓴 완성 문장이다. 원본에서 줄에 걸쳐 이어진 구절을 따로 읽을 때 생기는 불완전한 뜻을 피하고, 고학년은 문장 길이뿐 아니라 맞히다/맞추다, 쫓다/좇다, 지향/지양, 매다/메다, 낫다/낳다, 든지/던지, 의존 명사 등 실제 문맥 속 표기를 연습하도록 구성했다. 파일에서 쓰인 급수는 학년이나 공식 교육과정 수준으로 옮기지 않는다.

주제는 학교·배움, 친구·마음, 봄·여름, 가을·겨울, 건강·안전, 환경·생활, 1학기 계기교육, 2학기 계기교육이다. 각 주제는 학년별 10문장 한 묶음이므로 다시 뽑을 때 문장 수를 늘렸다고 표시하지 않고 ‘순서 바꾸기’라고 안내한다. ‘모든 주제’에서는 110개 중 10개를 뽑고 직전 문장을 우선 제외한다. 선택한 주제는 URL·설정에 저장하며 교사용 확인에는 주제와 표기 학습 초점을 함께 표시한다.

기존 기본 문장의 ID와 문장을 유지한다. 이전 주제 없는 저장 주소의 문장 ID도 그대로 복원한다. 주제가 지정된 주소는 해당 주제 밖의 문장을 포함할 수 없다.

## 영어 받아쓰기

`받아쓰기.html?subject=english`에서 초등 3~6학년의 영어 문장을 연습한다. 1~2학년은 영어 선택지에 넣지 않는다. 학교·친구, 하루·가족, 음식·가게, 날씨·바깥활동의 네 주제에 학년마다 10개씩, 총 160문장을 새로 작성했다. 전체 40개에서 중복 없는 10개를 고르거나 주제별 10문장의 순서를 바꾼다. 3학년은 익숙한 낱말과 짧은 기초 문장, 4학년은 질문·위치·수와 can, 5학년은 일상·시간·빈도·부탁, 6학년은 과거·미래·비교·연결 문장으로 구분한다. 공식 성취기준 전체를 평가하는 문항이라고 표시하지 않는다.

영어는 `en` 음성만, 국어는 `ko` 음성만 선택 목록에 표시한다. 선택한 음성의 언어를 사용하고 기본 영어는 `en-US`다. 첫 읽기의 번호도 `Number 1`처럼 영어로 읽는다. 교사용 확인에는 우리말 뜻이 있지만 음성에는 영문 문장만 전달하며 학생용에는 문장과 뜻이 노출되지 않는다. 영어 안내는 대문자·띄어쓰기·문장 부호를 살피도록 한다. 언어 변경은 현재 음성과 대기 시간을 취소하고 새 문제지를 만든다. 기존 언어 매개변수가 없는 국어 저장 주소는 국어로 유지한다.

기기의 기본 음성 합성 기능을 사용하며 외부 AI API·키·새 유료 서비스는 도입하지 않는다. 실제 기기의 발음 품질은 별도 청취 확인이 필요하다.


## 연습 급수와 자료 조사 (2026-10-26)

‘주제 · 연습 급수’에서 1~4학년의 연습 1~10급을 고른다. 각 급은 10문장이다. 급수마다 학습 요소를 표시하고, 인쇄물 하단과 저장 주소에 급수를 남긴다. 다른 학년으로 바꾸면 그 학년의 급수 이름을 다시 읽으며, 5~6학년에는 급수를 표시하지 않는다. 기존 문장 ID는 바꾸지 않았다.

이 급수는 클라시트 자체 연습 순서다. 학교 급수표나 공식 교과서 단원·학기와 일치한다고 표시하지 않는다. 저학년은 받침·모음·조사·문장 부호, 3~4학년은 겹받침·혼동 어휘·높임·의존 명사·호응으로 연습 범위를 넓힌다. 모든 항목을 완결된 문장으로 작성했다. 원문에서 추출한 구절이나 추출 과정에서 붙어 버린 띄어쓰기를 그대로 수록하지 않았다.
