## 소재 다양성

- 1–2학년: 우화·일상 동화, 횡단보도 안전, 식물 돌보기, 놀이터 약속, 그림자, 안내 방송, 분리배출
- 3–4학년: 우화·협력 이야기, 급식 과정, 물순환, 지역 변화 조사, 스마트 기기 알림, 행사 공고, 별 관찰 안내
- 5–6학년: 칭찬의 의도·협동·토론 문학, 데이터 해석, 인공지능 답변 검증, 빗물정원, 의사 결정, 유물의 증거와 한계, 설문 조사

## 검증 및 수업 전 확인

1. 지문 ID, 학년군과 장르의 균형, 5문항 구성, 고유 정답 및 오답 선택지, 해설과 평가 요소 검사
2. 읽기/듣기 본문 재사용, 듣기 전용 질문 2개 및 각색 출처 검사
3. 1~6학년, 5·10·15·20문항의 읽기/듣기 및 문학/비문학 출제 회귀 테스트
4. 기존 교과 문제지, 국어 평가, 학생용 듣기 대본 은닉과 A4 인쇄 브라우저 테스트
5. 현장 교사의 어휘 적합성·정답 유일성·상황 맥락 최종 검수와 실제 기기 TTS 발음·속도 확인

자동 검증은 교육과정 적합성과 채점의 완벽함을 입증하지 않는다. 새 자료는 모두 '수업 전 교사 검수 필요' 상태이며, 전문가 검토와 실제 교실 사용 확인 전까지 검수 완료로 표시하지 않는다.
