# 국어 읽기·듣기 평가 지문 및 문항 문장 품질 2차 검수

작성일: 2026-11-09

## 검토 대상과 방법

대상은 클라시트 공통 국어 평가 지문 48편(기존 12편, 신규 36편)과 읽기 기본 240문항, 듣기 변형 질문 96개이다. 지문 전개, 학생 연령에 맞는 자연스러운 문장, 질문-근거 일치, 선택지의 타당성, 반복되는 교훈형 문장, 문화·고전의 중립성을 기준으로 원문을 검토했다. 검수자가 교육 현장에 있는 교사의 최종 검토를 대체하지 않는다.

## 주요 발견과 수정

| 분야 | 이전 문제 | 수정 방향 |
|---|---|---|
| 어색한 등장인물 관계 | '같은 학년의 동생' | '한 학년 아래인 학생'으로 관계 명확화 |
| 과학적 용어 | 물에 비친 개의 모습을 '그림자'라고 서술 | '물에 비친 자신의 모습'으로 수정 |
| 사실관계가 부자연스러운 상황 | 쓰레기가 많은 날 곤충 관찰이 어렵다고 단정 | 바람 때문에 수면이 흔들려 관찰이 어려웠다는 상황으로 변경 |
| 부자연스러운 나열 | '다음은 가상 ...', '가상의 학교 ...' | 학생용 실제 안내문 말투로 수정하고 창작 여부는 출처 메타데이터에 유지 |
| 교훈을 너무 직접 설명 | '이 이야기는 ... 중요함을 보여 준다', '... 깨달았어요' | 인물의 대화·행동과 결과로 보여 주어 독해·추론의 여지 확보 |
| 기계적인 5문항 질문 | 빈번한 '중심 생각은 무엇인가요?'와 무관한 오답 | 일부를 인물의 판단·근거 비교로 바꾸고 지문과 연결되는 대안 선택지 강화 |
| 고학년 오답 품질 | '카메라 판매 가격', '급식 메뉴' 등 쉽게 배제되는 선지 | 같은 상황에 있을 법하지만 본문과 맞지 않는 선지로 교체 |
| 평가 요소 | 대본/해설이 원문 교훈이나 허위 상황을 가리킴 | 수정한 지문에 맞게 일부 해설과 질문, 듣기 근거 재검토 |

## 품질 기준

1. **문장 자연스러움:** 어린이의 실제 말투나 안내문·설명문의 장르에 맞는 어조 사용. 가상의 학교 활동을 설명하는 제작자 문구를 학생용 본문에 넣지 않는다.
2. **추론 문항:** 정답을 마지막 문장에 그대로 설명하지 않고 인물의 행동과 상황 변화로 뒷받침한다.
3. **오답 매력도:** 지나치게 황당한 오답, 다른 교과의 맥락 없는 단어, 정답과 의미가 겹치는 선택지를 배제한다.
4. **정확성:** 물속 반사와 그림자 같은 기초 개념을 혼용하지 않는다. 학생의 안전과 연관된 안내는 오해 없이 작성한다.
5. **중립성:** 고전의 사건·구절과 창작 학교생활 사례를 구별하며 신앙적 정답을 요구하지 않는다.
6. **보존:** 변경 중에도 기존 문제은행의 ID, 48편 분배, 한 지문당 5문항, 읽기·듣기 본문 공유, 음성·인쇄·채점·저장을 유지한다.
