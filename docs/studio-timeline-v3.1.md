# 뚝딱 제작실 3.1 — 장면 타임라인, 등장 효과, WAV 배경음악

## 구현한 편집 경험

3.0의 `통합 캔버스` 요소 모델을 유지하면서, **같은 프로젝트 안에서** 여러 장면의 길이·전환·개별 요소 등장·배경음악을 설정하고 재생할 수 있도록 확장했습니다. 기존 도안·발표·문서·음악·영상 편집기를 삭제하거나 옮기지 않습니다.

### 장면 타임라인

- 화면 아래 `장면 타임라인`은 모든 페이지를 재생 순서대로 표시합니다. 페이지별 **1~20초** 길이를 입력할 수 있으며 전체 길이가 자동 계산됩니다.
- 재생·일시정지·정지·재생 위치 이동을 지원합니다. 선택한 장면을 클릭하면 해당 시점으로 이동합니다.
- 장면 전환은 `바로 바꾸기`, `서서히 나타나기`, `옆에서 들어오기` 세 가지입니다.
- 재생 후 원래 편집 상태로 돌아가면 요소가 다시 모두 표시됩니다. 재생 중 요소를 누르면 재생을 중단하고 편집합니다.

### 요소 애니메이션

- 기존 글씨·사진·도형을 선택해 `효과 없음`, `서서히 나타나기`, `아래에서 올라오기`, `확대 등장` 중 하나를 지정합니다.
- 개별 요소의 등장 지연은 **0~20초**입니다. 지연이 해당 장면 길이보다 길면 그 장면 동안 요소가 등장하지 않을 수 있습니다.
- 요소/장면별 설정은 동일한 통합 프로젝트의 편집 데이터로 저장되며 실행 취소·다시 실행에 포함됩니다.

### 로컬 배경음악

- 이전 음악 제작실에서 내려받은 WAV 또는 기기의 WAV 파일을 선택합니다. 기존 로컬 미디어 보관함에 저장한 WAV도 다시 선택할 수 있습니다.
- 최대 **15MB**의 WAV 원본을 이용하며, 기존 미디어 보관함의 최대 **18개** 제한을 유지합니다.
- 음악 크기(0~100%), 반복 여부를 선택할 수 있습니다. 오디오는 브라우저의 재생 정책 및 WAV 디코딩 지원에 영향을 받습니다.
- 음악 파일은 서버로 전송되지 않으며, 사용자의 **브라우저 IndexedDB**에 저장됩니다. 프로젝트에는 WAV 바이너리가 아닌 로컬 미디어 ID만 저장됩니다.
- **기존 ZIP/JSON 전체 백업·복원에 WAV 원본이 포함되고**, 복원할 때 WAV ID를 새 프로젝트의 로컬 ID로 다시 연결합니다. WAV가 누락된 손상된 백업은 성공으로 처리하지 않습니다.

## 이전 프로젝트 호환성

기존 `gulliver.unified.canvas.v1` 모델의 형식을 변경하지 않습니다. 기존 3.0 프로젝트에 새 필드가 없더라도 페이지 5초, 전환 효과 없음, 개별 요소 등장 효과 없음, 배경음악 없음으로 읽을 수 있습니다.

원본 도안·발표 작업은 3.0처럼 복사 변환되므로 기존 프로젝트는 덮어쓰지 않습니다.

## 현재 3.1의 범위와 후속 단계

3.1은 **통합 캔버스 내부 재생 프리뷰 및 편집 가능한 장면 타이밍** 구현입니다. **애니메이션을 입힌 실제 동영상/WebM/MP4 파일 인코딩은 아직 지원하지 않습니다.** 기존 `영상 뚝딱`의 이미지 기반 전송은 그대로 사용할 수 있지만, 해당 전송은 편집 가능 애니메이션을 유지하지 않습니다. 장면 재생을 영상으로 녹화·출력하고 오디오를 합치는 기능은 3.2에서 성능·브라우저 호환성을 검증하며 설계해야 합니다.

iPhone/iPad Safari에서 영상·음악·애니메이션 실행은 실기기 검증이 필요합니다. Chrome 자동화 테스트만으로 Apple 기기의 모든 미디어 동작을 보장하지 않습니다.
