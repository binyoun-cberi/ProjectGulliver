# QR 타자 연습

국어 타자·영어 타자를 홈의 말하기/타자 영역에 추가한다. 교사는 언어·학년·문제 수(5/10/15/20)·24시간/일주일 유효기간을 골라 QR을 만든다. 공유하기 전에 출제 문장을 확인하고 주소를 복사하거나 학생 화면을 열 수 있다.

말하기의 WorksheetSpeaking.generate(kind=sentence)를 재사용한다. 문장은 국어/영어 받아쓰기 은행의 원문이며 별도 타자 문제은행은 만들지 않는다. QR에 고정 문장 ID를 담아 문장이 추가되어도 같은 과제를 복원한다. 마이크와 음성 인식을 사용하지 않는다.

학생은 제시 문장을 보고 직접 입력한다. NFC 정규화와 앞뒤 공백 제거 후 비교하며 문장 안의 띄어쓰기·대소문자·문장 부호는 정확히 맞춰야 한다. 글자별 위치가 맞으면 초록색, 다르면 빨간색이다. 한글 조합 중에는 판정하지 않는다. 문장 전체가 확정되면 650ms 후 자동으로 넘어간다. ‘다음 문제’는 넘김으로 집계하며 결과는 맞힌 수/전체 수와 넘긴 수다. 넘긴 문제만 다시 연습할 수 있다.

동일 주소로 연 학생도 탭별 sessionStorage를 사용해 독립적으로 진행한다. 같은 탭 새로고침 후 이어하기를 지원한다. 저장하는 것은 문항 순서·정답/넘김 기록뿐이며 학생의 입력문·이름은 저장하지 않는다. 학생별 서버 수집이나 교사용 성적 집계는 포함하지 않는다. 기기 시간에 따른 만료는 말하기와 동일하며 위변조 방지용 서버 검증은 아니다. 인쇄용 문제지와 별개인 화면 연습이다. 화면 이탈·쉬기·만료 시 예약된 자동 진행을 취소한다.

검증: 국어·영어 원문/고정 ID/QR 생성, 한글 조합·반복 이벤트·자동 진행, 오타, 넘기기, 일시정지, 두 학생 진행 독립, 새로고침 후 상태, 재연습 점수, 만료·만료 경계의 전환 취소를 테스트한다. 모바일 키보드의 실제 자동완성·글꼴·음성 기능은 브라우저와 기기 설정에 따른다.
