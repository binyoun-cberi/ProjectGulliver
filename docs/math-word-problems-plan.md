# 수학 문장형 문제 분류안

목표: 계산식만 바꾸는 문제가 아니라, 상황을 읽고 필요한 정보와 연산을 선택하도록 한다. 학년과 유형 선택 뒤 5·10·15·20문항을 생성하며 학생용에는 답을 숨기고 교사용에는 식과 이유를 표시한다.

| 학년 | 유형 | 대표 상황 | 답 검수 |
| --- | --- | --- | --- |
| 1·2 | 합치기·남은 양·비교 | 교실 물건 수와 그림 자료 | 0 이상, 학년별 수 범위 |
| 3·4 | 묶음·나눔·시간·길이 | 준비물 배분, 이동 시간 | 몫·나머지 의미와 단위 |
| 5·6 | 비율·분수·소수·자료 해석 | 급식량, 조사표, 여러 단계 계획 | 단위와 풀이 순서, 조건 충분성 |

각 유형은 서로 다른 상황과 질문 목표를 20개 이상 제공한다. 생성기는 수치를 바꾸되 인물 이름만 바꿔 문항 수를 채우지 않는다. '필요 없는 정보가 있는 문제', '정보가 부족해 풀 수 없는 문제', '두 풀이 비교'는 별도 고급 유형으로 분리한다. 동일 문제지의 질문·자료·정답 반복을 검출하고, 학년별 수 범위·음수·나머지·단위를 자동 검사한다. 교사가 일부 유형을 체크해 섞을 수 있도록 수학 혼합 선택기에 연결한다.

다음 구현 순서: 1·2학년 합치기·남은 양 → 3·4학년 묶음·나눔 → 5·6학년 자료 해석. 각 단계마다 정답 및 지면 표본을 검수한다. 성취기준 코드는 원문과 문항을 대조한 뒤에만 붙인다.
