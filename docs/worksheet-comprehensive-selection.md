# 종합 연습 전용 범위 선택

국어·수학·사회·과학의 종합 연습에만 단원별 체크 목록을 표시한다. 차시별·성취기준별 선택창은 그대로 유지한다. 오른쪽에서 단원을 펼쳐 유형을 체크하고, 왼쪽에서 선택한 유형과 문항 수를 조정한다. 선택 행에는 단원 이름도 함께 표시한다. 검색, 단원 전체 선택·부분 선택 표시, 선택 비우기를 제공한다. 모바일에서는 범위 목록 다음에 선택 요약을 표시한다.

차시 목차를 복제하지 않고 실제 종합 생성기의 `DailyWorksheetCore.mixOptions`를 사용한다. 최대 20개 유형·총 40문항, 유형별 1~20문항(세로셈 12문항)이다. 단원 전체 선택으로 새로 담는 유형은 1문항, 개별 선택은 5문항으로 시작한다. 기존 단일 연습 주소는 현재 유형을 선택 목록으로 가져오며, 기존 `unitMix` 주소는 그대로 복원한다. 역사 문제의 응답 형식은 선택한 행의 객관식·단답·OX·초성을 적용한다.

기존 혼합 생성 모델과 저장 주소·인쇄 경로를 재사용한다. 범위나 문항 수를 바꾸면 이전 문제와 인쇄 버튼을 초기화한다. 선택이 없거나 수량이 잘못되면 생성 버튼을 비활성화한다. 큰 글씨 전환은 선택한 문제를 보존한다.

검증: 네 과목의 체크 선택, 유형별 3+7문항, 주소 복원, 큰 글씨, 검색, 전체 선택과 부분 선택, 비우기, 차시·성취 화면 복귀. 실제 Chromium에서 고려·조선 초성 혼합 10문항, 주소 복원, 390px 모바일 가로 넘침 없음, 학생/교사용 A4 인쇄를 확인했다. 기존 차시 트리와 사회 전체 생성 감사도 통과했다.
