# 단원·학습 내용 제작 흐름 (2026-10-25)

기본 제작 흐름을 과목 → 학년 → 학기 → 실제 단원 → 차시의 학습 내용 → 답안 유형으로 변경한다. 이전 URL과 넓은 영역별 연습은 '기존 연습에서 고르기'에서 유지한다.

## 수집 자료

- 2022 개정 미래엔 공개 목차 52권분(국어 가·나 포함), 40개 과목·학년·학기 조합.
- 상위 항목 229개, 차시 제목 1,973개. 독서·연극·시작/정리 활동도 보존하므로 이 수를 정규 대단원·학습 목표 수로 해석하지 않는다.
- `data/worksheet-textbooks.js`는 수집한 단원 트리에서 상위 항목과 그 아래 차시를 추출한 정적 데이터다. 원래 단원 번호, 권명, 소단원명, 차시명, 시작 쪽, 공개 출처 URL을 남긴다.
- 부도·독도 보조교재·[보완] 과학 자료는 정규 제작 메뉴에서 제외했다. 본문·기성 문제·인증이 필요한 수업 자료는 포함하지 않는다.
- 기본 목차는 한 출판사 기준이며 전 출판사 공통 순서라는 뜻이 아니다. 출판사별 차시 대응표는 추가 검증이 필요하다.

## 연결 원칙

`worksheet-learning.js`의 명시적인 학습 내용 규칙으로만 연결한다. 문항에 차시 ID를 남기고 문제지에도 학년·학기·단원·학습 내용·연습 범위를 기록한다. 학년·학기·단원·차시가 맞지 않거나 연결이 없으면 생성 오류를 반환한다. 다른 단원 문제로 빈자리를 채우지 않는다.

1차 도입 시 연결: 수학 58, 국어 10, 사회 2, 과학 19개 차시 제목, 합계 89개. 하나의 학습 목표가 여러 차시에 걸쳐 나타날 수 있으므로 서로 다른 목표 89개 또는 전체 차시 구현 완료라는 뜻이 아니다. 과학은 질문 ID까지 제한하고 작은 묶음은 실제 문항 수 이내에서만 선택한다. 계산과 자료 해석은 검증된 생성 조건으로 만든다. 글쓰기에는 확인할 요소를 제공한다.

차시 제목에서 확인할 수 없는 세부 난도는 추정하지 않는다. 예를 들어 세 자리 수 덧셈(1)이라는 제목만으로 받아올림 횟수를 추정하지 않고, 연결한 연습이 '받아올림 없는 계산'임을 별도 표시한다. 해당 차시의 전체 평가라는 표시는 하지 않는다.

## 미완료 범위

나머지 차시 문항 연결, 출판사 간 대응, 여러 실제 단원을 합치는 새 혼합 제작은 남아 있다. 기존 혼합 연습은 기존 연습 모드에만 제공한다. 이 문서는 그 범위를 완료했다고 주장하지 않는다. 성취기준 연결도 새 단원 체계에서는 미확정이며, 기존 연습 모드의 수업 참고를 보존한다.

## 검증

- 40개 조합의 존재, 원문 출처, ID 고유성, 보완 자료 제외.
- 모든 연결 차시에서 지원하는 문항 수·유형·시드의 재현성, 중복·정답·해설·문항별 차시 ID 확인.
- 연결 없는 차시, 다른 학기, 지원하지 않는 유형, 은행보다 큰 문항 수 거부.
- 원래 문제 생성기의 회귀 검사 유지.

다음 확장은 차시별로 자료·핵심 개념·오답 근거를 검토한 뒤 연결 규칙을 추가한다. 준비 중인 차시를 넓은 은행에 자동 연결해 준비 완료로 바꾸지 않는다.


## 2차 보강: 자료를 갖춘 문제 묶음

- 창작 문제 묶음 15개, 문항 75개 추가. 사회 10묶음(기호·범례, 축척, 장소의 역할, 과거 자료, 시간 순서, 합리적 선택, 교류, 민주적 결정, 지역문제, 자연·인문환경), 과학 3묶음(물의 상태, 증발·끓음, 응결), 국어 2묶음(중심 내용, 사실·의견).
- 연결된 차시 제목은 수학 58·국어 15·사회 32·과학 23개, 총 128개로 늘었다. 기존 89개에서 39개 증가했다. 같은 목표가 여러 제목에 등장할 수 있으므로 고유 학습 목표 수로 해석하지 않는다.
- 각 문항에 독립적인 사례·기록표·정답·오답·해설을 작성했다. 다섯 문항짜리 묶음은 최대 다섯 문항만 제공하며, 숫자나 장소를 바꿔 스무 문항으로 부풀리지 않는다.
- 세부 차시에 따라 묶음 안에서도 사용할 질문 ID를 제한한다. 예: 일기·편지 차시는 일기 질문 1개만, 사진·그림 차시는 관련 질문 2개만 제공한다. 단원 도입·정리 활동은 자동 연결하지 않는다.
- 표는 기존 자료 렌더러로 인쇄하고 글 자료는 본문으로 표시한다. 사진을 실제로 제공하지 않는 경우에는 사진 관찰 메모임을 명시한다.
- 이전의 '알맞은 것'을 쓰기형으로 변환할 때 일률적으로 '마음을 쓰세요'로 바꾸던 문구를 일반적인 '알맞은 답을 쓰세요'로 수정했다.
- Chrome 시각 검증은 여전히 미완료다. DOM 검사에서 사회 축척의 표·선택지 표시까지 확인한다.
