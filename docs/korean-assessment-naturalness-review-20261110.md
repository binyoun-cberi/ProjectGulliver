# 국어 지문·읽기·듣기 문항: 생성형 AI 문체 3차 편집 검수

작성: 2026-11-10

## 검수 범위

기본 브랜치의 공통 국어 읽기·듣기 평가 지문 48편(1–2, 3–4, 5–6학년 각 16편)을 모두 다시 읽고, 기본 읽기 240문항 및 독립 듣기 변형 96개를 함께 대조했다. 검수는 **문장/전개 자연스러움, 사람의 행동과 시간의 개연성, 인과관계, 문항 정답의 본문 근거, 오답의 현실성, 연령·장르별 문체** 중심이다. 모든 문항이 현장 전문가 검수를 통과했다는 의미가 아니며, '수업 전 교사 검수 필요' 표시를 유지한다.

## 발견한 문제와 수정

| 대상 | 이전 문제 | 편집 결과 |
|---|---|---|
| 1–2 「병아리가 건넌 길」 | 작은 물웅덩이에 물살이 흐른다는 부자연스러운 설정 | 나뭇잎이 바람에 밀리도록 수정하고 듣기 해설도 함께 변경 |
| 1–2 「파란색을 기다리는 동안」 | 친구의 도움으로 그림을 끝냈다는 도식적 줄거리 | 친구의 실제 대화, 색연필을 기다리는 동안의 행동과 개별 그림을 구체화 |
| 3–4 「두 친구의 약속」 | 결석한 학생이 발표 직후 등장해 갑자기 말을 건넴 | 다음 날 등교 후 나눈 대화로 시간의 흐름을 보완 |
| 3–4 「나무 아래에 놓은 벤치」 | 작은 의자 하나를 주민 모두가 이용한다는 설정과 지나치게 일반적인 결말 | 실생활에서 함께 이용할 벤치, 부서진 다리, 구체적인 행동과 대사로 재작성 |
| 3–4 위 벤치 듣기 평가 | 수정된 본문에는 없는 ‘주민들의 약속’을 정답으로 묻고 있었음 | 본문에 나오는 ‘먼저 앉은 사람’을 물어 정답 근거 일치 |
| 3–4 「운동화의 새 주인」 | 등장인물 둘 다 웃으며 끝나는 반복적인 감정 묘사 | 운동화를 직접 신어 보고 걸어 보는 행동을 중심으로 수정 |
| 3–4 급식·행사 안내문 | 다소 공식적이고 인위적인 나열/설명 | 실제 급식실 업무와 행사 사전 신청에 맞는 서술로 수정 |
| 5–6 「칭찬에 넘어간 까마귀」 | 교훈을 장황하게 직접 설명하거나 같은 생각을 반복 | 까마귀의 동작과 여우가 치즈를 먹는 장면으로 결말 변경 |
| 5–6 「지도만 보고 갈 수 있을까?」 | 지도에 물에 잠긴 길이 원래부터 표시된 듯한 모호한 표현 | 학생이 직접 지도에 침수 구간을 표시하도록 수정 |
| 5–6 「서로 다른 색으로 그린 벽화」 | '의견을 연결했다'는 인위적 결말 | 복도 가운데 공간에 대한 갈등과 강가의 그림을 덧그리는 행동 제시 |
| 5–6 「책 한 권이 건넌 다리」 | 교환 목록 만들기와 상호 배려가 지나치게 절차적으로 나열됨 | 실제로 받은 책의 첫 장에 끼운 추천 글을 묘사하는 장면 추가 |
| 5–6 「첫 발표보다 나은 두 번째 발표」 | 모두가 친절하게 합의하는 정형적 토론 | 질문을 듣고 당황하는 장면, 다음 발표의 근거 자료를 구체화 |
| 5–6 「인공지능이 알려 준 답」 | '달에서 소리가 들릴까?'가 매체·상황에 따라 해석이 달라짐 | '달 표면에서 통신 장치 없이'로 과학적 논의 범위를 분명히 하고 질문·해설도 수정 |
| 세계 고전 「법구경」 각색 | 가정형 '두 학생이 있다고 합시다'에서 과거 실제 사건으로 시점이 바뀜 | 한 가지 교실 사례로 전개를 통일. 듣기 평가의 기존 '언성을 낮췄다'라는 본문에 없는 정답도 수정 |
| 고학년 및 듣기 평가 | 수영장·우주선 등 글과 전혀 관련 없는 오답이 다수 | 비교 가능한 장소·상황·행동으로 선택지를 교체하되, 복수 정답이 생기지 않도록 검토 |

## 남아 있는 한계

1. 짧은 저학년 이야기에서는 반복적인 문장 어미 자체가 읽기 발달에 도움이 될 수 있어 모두 없애지 않았다.
2. 고학년은 학교 배경의 창작 글 비율이 높아, 장기적으로 실제 논설문·인터뷰·시·기록문·기행문·매체 자료 등 **글의 종류와 서술 방식 자체**를 더 넓힐 필요가 있다.
3. 선택형 오답의 자연스러움은 편집자가 검사했지만 실제 학생의 정답률·문항 변별도와 복수 정답 판단은 초등 국어 교사의 실물 검수·응답 데이터가 필요하다.
4. 실제 학생 듣기 속도와 음질, 음성으로 듣기 어려운 문장은 기기·TTS 음성별 현장 재생 확인이 필요하다.
5. 고전·종교 관련 지문은 원전 출처와 현대 한국어 각색의 구분을 계속 유지하며 특정 신앙을 정답으로 요구하지 않는다.
