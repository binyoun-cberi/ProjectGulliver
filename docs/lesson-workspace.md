# 수업 작업실

수업 프로젝트 안에 발표·문서·도안의 편집 원본과 영상·음악·PDF 파일을 넣고 순서를 정한다. 기존 제작실 프로젝트는 검증 후 독립 복사한다. 원본 제작실 작업을 덮어쓰지 않는다.

- 편집: 기존 세 편집기를 동일 출처 iframe으로 연결하여 capture/apply API 사용. 선택한 활동 ID가 일치할 때만 캡처하여 같은 종류의 자료 간 이동 시 덮어쓰기 방지.
- 수업 진행: 발표는 페이지 단위, 나머지는 활동 단위로 이전/다음 이동. 문서와 도안은 검증된 원본을 렌더링. 편집 복귀 시 진행 위치 유지.
- 미디어: 영상 MP4/WebM/Ogg, 음악 MP3/M4A/WAV/Ogg/WebM, PDF. 파일당 100MB. Blob을 IndexedDB에 보관하며 URL은 재생 후 해제. 시작/끝 구간, 음량, 구간 반복. 배경음악은 다음 활동에서도 지속되고 종료 시 정지.
- 저장: 별도 gulliver-lessons-v1 DB에 lessons/assets. 기존 제작실·우리 반 저장소는 유지. 매 변경 자동 저장 및 명시적 저장.
- 백업: lesson.json에 검증한 수업과 참조 미디어만 포함. 미디어 합계 200MB 제한. 불러오기 시 모든 활동·파일을 검증하고 새 ID를 부여한 뒤 단일 트랜잭션에 원자적으로 저장한다.

현재 발표·문서는 뚝딱 원본 편집을 지원한다. 외부 PPTX/DOCX/HWPX의 원형 보존 가져오기와 영상·음악의 새 파일 렌더링은 아직 지원하지 않는다. 영상·음악 구간 설정은 수업 재생 설정이며 원본 파일을 변경하지 않는다. PDF는 표시 전용이다. 수업 파일은 기기·브라우저 간 자동 동기화되지 않는다.
