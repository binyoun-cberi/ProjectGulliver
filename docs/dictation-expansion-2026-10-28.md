# 받아쓰기 문장 보강

국어 1,180 → 1,360문장, 영어 160 → 320문장으로 총 340문장을 추가했다.

- 국어 1~6학년 기본 문장: 각 30 → 50문장. 총 120개 추가.
- 받침 집중 6묶음: 각 20 → 30문장. 총 60개 추가. 기본 받침, 소리와 다른 표기, 모음 앞 이어 읽기, 겹받침을 기존 선택 항목에서 연습한다.
- 영어 3~6학년 × 학교·가정·음식·바깥활동: 각 10 → 20문장. 번역과 함께 총 160개 추가.

기존 문장의 순서와 ID를 보존해 저장한 받아쓰기 및 말하기 과제가 그대로 복원된다. 주제별 개수는 실제 은행에서 계산한다. 새 문제 만들기의 제외 ID를 누적하면 국어 기본 5회, 받침 집중 3회, 영어 주제 2회를 각각 10문장씩 중복 없이 추출할 수 있다. 화면에서 이전 회차 하나만 제외하는 동작은 그대로 유지한다.

검수: 학년별 문장 길이와 종결 표현, 영어 문법·번역 및 학년별 평균 낱말 수, 전체 문장과 ID 중복, 저장한 문장 ID 복원, 주제 메뉴의 실제 개수, 여러 회차의 중복 없는 추출을 검사했다. 기준 main의 기존 문장을 ID별로 대조하여 본문·번역이 바뀌지 않았음을 확인했다. 이번 변경은 문장 데이터와 표시 개수·캐시 버전이며 음성 엔진은 변경하지 않는다.
