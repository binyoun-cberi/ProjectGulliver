# 클라시트 문제지: 출제 → 비평 → 반론 → 개선 루프

## 목적과 한계

문제지가 **생성된다는 사실**과 **수업에 사용할 만하다는 사실**을 구분한다.
국어·수학·사회/역사·과학·영어, 1~6학년 중 제공되는 모든 유형을 대상에 포함한다.
자동 코드는 정답 유무·중복·보기 일치 같은 확정 조건과, 맥락·오답 구성·자료-정답 관계에 관한 **검토 후보**만 포착한다. AI가 여러 명 독립적으로 토론하는 기능은 구현하지 않았다. 실제 독립 비평은 이 보고서와 문제 원문·PDF를 가지고 사람이 수행한다.

기존 [품질 계약](worksheet-quality-process.md)의 제안자–도전자–조율자를 더 구체적으로 운영하는 절차다.

## 검수 준비

- 기본 표본: \`node scripts/worksheet-critique-loop.cjs\` (모든 제공 학년·단원·세부 유형 × 고정 시드 2개)
- 확대 표본: \`node scripts/worksheet-critique-loop.cjs --full\` (응답 방식도 순회하고 시드 3개)
- 결과: \`test-artifacts/worksheet-critique/review.md\`, \`report.json\`
- 기존 정확성 검사: \`node --test tests/daily-worksheet-core.test.cjs tests/daily-worksheet-challenger.test.cjs tests/worksheet-critique-loop.test.cjs\`
- 인쇄 실물: 기존 GitHub Actions의 Chrome/A4/PDF 품질 게이트 결과와 파일 확인
- 시드·학년·단원·응답 방식·문항 번호를 기록하고, **학생용과 교사용**을 함께 검수한다.
- 동일 시드에서 실패가 재현되는지를 먼저 확인한 후 **새 시드**에서도 해결됐는지 검증한다.

## 5가지 집중 비평 단계

| 단계 | 비평 질문 | 반론 제기 방법 | 수정 우선순위 |
| --- | --- | --- | --- |
| 1 사실·정답 | 정답이 하나인가? 학년 내용에 맞는가? 원문과 출처에 근거하는가? | 다른 답도 가능한 반례 또는 단위·연표 오류 제시 | 사실 오류는 즉시 수정 |
| 2 맥락·자료 | 그림·표·지문이 없으면 못 푸는 문제인가? 관찰 결과에서 결론이 따라오는가? | 문장을 가린 뒤 자료만, 자료를 가린 뒤 질문만 읽어 보기 | 인과 비약·맥락 부족 개선 |
| 3 사고·선택지 | 단순 암기 반복이 아닌 비교·분석·추론·설명이 있는가? 오답이 실제 오개념을 반영하는가? | 황당한 보기 제거 후에도 문제 성립하는지 검토 | 낮은 변별력 개선 |
| 4 다양성·표현 | 시드 변경 시 상황·목표·자료·표현이 모두 달라지는가? 문장에 개발자 말투·번역투가 있는가? | 같은 뜻의 문항, 반복 정답, 불필요한 단서 찾기 | 표현 및 소재 교체 |
| 5 인쇄·접근성 | A4에서 짤리지 않는가? 소량 문항에도 답 쓸 곳이 있는가? 그림·번호·출처가 읽히는가? | 실제 PDF 확대 및 작은 글씨/큰 글씨, 학생·교사 비교 | 누락·잘림은 즉시 수정 |

## 도전자 역할 분리

**제안자**: 대상 단원의 학습 목표와 각 문항의 정답 근거, 예상 풀이 행동을 설명한다. 수정안은 문구만 바꿀지, 자료·출제 규칙·문제은행 자체를 바꿀지 구분한다.

**교육과정 도전자**: 제안한 문제가 학년군 학습 범위를 벗어나는지, 자료로부터 내릴 수 없는 결론을 강요하는지 찾는다. 실제 교과 내용이나 출처가 확인되지 않으면 통과시키지 않는다.

**수업 현장 도전자**: 학생이 문제를 어떻게 읽고 풀지, 그림 없이 추론 가능한지, 오답이 왜 틀렸는지 납득할 수 있는지 지적한다. 긴 지문·풀 공간·유아/특수교육 접근성 필요도 함께 본다.

**조율자**: 반례가 원문·코드·시드·실물 출력과 일치하는지 확인하고 확정 오류 / 개선 권장 / 판단 보류로 분류한다. 세 의견 모두 한 사람이 순서대로 수행할 경우에도 **독립 검토가 이루어졌다고 표현하지 않는다.**

### 반례의 예: 수조 관찰 기록

- 1일: 어른 물고기 2마리
- 8일: 어른 물고기 2마리와 새끼 물고기 6마리
- 질문: "이 기록이 보여 주는 생물의 특징은?"

**도전자 반론**: 단순히 개체 수가 달라졌다는 기록만으로 **수조 속 물고기의 번식**이 확인되었다고 단정할 수 없다. 새끼를 다른 수조에서 옮겼을 수도 있다. 설명 없이 정답만 요구하면 학생의 추론이 아니라 출제자의 의도 맞히기가 된다.

**수정 방향 A(관찰 근거 강화)**: 외부에서 물고기를 넣지 않았고, 수조 안에서 새끼가 태어났다는 관찰 기록을 명시한다. 질문은 "어떤 변화가 관찰되었고, 어떤 생물의 특징과 관련 있는가?"처럼 증거를 말하도록 바꾼다.

**수정 방향 B(자료 해석 집중)**: 결론을 "번식"으로 강제하지 않고 "1일보다 8일에 새끼가 6마리 더 관찰되었다"라는 **실제 표가 보여 주는 변화**를 고르게 한다. 두 과제를 다른 사고 목표로 분리할 수 있다.

## 과목별 필수 검수

- **국어**: 독해 글의 자연스러움, 지시어가 가리키는 대상, 글에 없는 마음·의도 추정, 지문 하나당 질문 다양성.
- **수학**: 사칙연산 정확성, 학년별 수 범위, 받아올림·받아내림·나머지 조건, 도형 그림의 일관성, 세로셈 자리 정렬, 풀이 칸.
- **사회·역사**: 지도의 방향·기호, 출처·문화유산 사진, 사실과 해석의 구분, 시대착오, 같은 인물만 반복되는 편향.
- **과학**: 관찰/대조군/변인/측정단위, 표·그래프의 출처와 해독 가능성, 표에 없는 인과 주장, 비현실적인 오답.
- **영어**: 자연스러운 맥락과 발화, 철자·문법·의미, 오답의 언어적 그럴듯함, 읽기·쓰기와 듣기·말하기 영역의 구별.

## 100점 교육 품질 점검표 (사람이 평가)

| 항목 | 배점 |
| --- | ---: |
| 사실·정답·근거의 정확성 | 25 |
| 학년·학습 목표 적합성 | 15 |
| 맥락·자료의 충분성 | 15 |
| 사고력과 문제 다양성 | 15 |
| 문장과 지문의 자연스러움 | 10 |
| 선택지의 타당성과 변별력 | 5 |
| A4 배치·가독성·풀이 공간 | 10 |
| 접근성 및 교사용 해설 | 5 |
| **합계** | **100** |

85점 이상이라도 정답 오류·출처 허위·개인정보 노출·페이지 잘림이 확인되면 **병합 보류**한다.
70~84점은 보완 후 재검수, 70점 미만은 문제 구성 자체를 다시 설계한다.
점수는 자동 보고서의 위험 신호 개수가 아니라 **실제 문제와 출력물을 읽고 평가한 증거**로 매긴다.

## 세 번 반복하는 방식

1. **1회차 — 결함 찾기**: 전 과목 빠른 표본을 만들고 확정 오류·위험 신호를 기록. 대표 문제지는 반드시 눈으로 읽는다.
2. **2회차 — 근본 원인 수정**: 여러 문항에 반복되는 결함은 문장 땜질 대신 출제 템플릿·자료 구조·선택지 생성 규칙을 수정. 제안자는 수정 전후 같은 시드를 비교한다.
3. **3회차 — 반례 재검증**: 도전자는 기존 실패 시드 + 새로운 시드, 다른 학년·과목과 학생·교사용 PDF로 회귀를 확인한다.
4. **보강 4~5회차(필요 시)**: 복합 지문·사회 역사 사료·과학 관찰 자료 또는 PDF 페이지 경계처럼 쉽게 놓치는 항목은 별도 심층 검수한다.
5. **종료 조건**: 확정 오류 0, 문제가 되는 검수 후보 해결 또는 판단 근거 기록, 정답·중복·브라우저·PDF 회귀 통과, 남은 한계 공개. 해결 실패 항목은 보류하고 자동 병합하지 않는다.

## 보고 방식

한 문항의 수정 기록은 \`과목/학년/단원/유형/형식/시드/번호 → 원본 질문과 자료 → 비평 → 도전자 반례 → 수정된 문제 → 확인한 정답 근거 → 출력 사진/PDF → 판정\` 순으로 남긴다.

검수 후보가 0건이더라도 "교육적 품질 통과"가 아니다. 기계 검사로 확인하지 못한 사고력·문장·사료 검토는 **미완료**로 표시한다. PR에는 예시 문제지와 개선 전후를 첨부하고 사람의 최종 승인을 받아 병합한다.
