# 하나의 작업실 — 공통 작업·저장 기반 1차

## 목표
제작 자료와 수업 준비가 같은 작업을 편집한다. 자료·활동 순서·교사 메모·대상·목표·미디어 참조를 한 작업 기록에 보관한다. 화면과 전문 편집 기능 이전은 이 기반 위에서 단계적으로 진행한다.

## 구현한 공통 모델
`gulliver.work.v1`은 작업 ID, 제목, 목표·대상, 순서가 있는 steps, 현재 위치, 수정 시각, revision을 갖는다. 각 step은 기존 편집 가능한 payload와 교사 메모, 미디어 참조를 유지한다. 기존 제작 자료에서 시작한 step에는 원본 프로젝트 ID를 연결한다.

`work-core.js`는 자료/수업 변환·미디어 ID 변경·호환 판단을 담당하고 `work-storage.js`는 공통 저장 기록과 기존 편집기용 조회 결과를 관리한다. 기존 studio DB를 버전 5로 올려 works/workAssets를 추가한다. 작업과 제작 자료용 조회 결과, 첨부 파일은 동일 트랜잭션에서 반영한다. 기존 수업 DB 원본은 지우거나 덮어쓰지 않는다.

- 제작 화면의 ‘수업 순서·메모’로 같은 자료를 수업 구성 화면에서 연다.
- 연결된 자료에서는 ‘자료 편집으로’로 되돌아간다. 별도 사본을 만들지 않는다.
- 자료를 수정해도 다른 활동과 교사 메모가 유지된다.
- 다른 창에서 수정한 뒤 오래된 창이 저장하면 충돌을 표시하고 저장을 거부한다. 같은 창의 자동 저장은 순서대로 처리한다.
- 같은 작업은 보관함에서 한 번 표시한다. 여러 활동을 갖는 연결 작업은 ZIP에서도 수업 기록으로 한 번 저장한다. 복원은 기존 동작처럼 새 작업으로 생성하며 자료·순서·메모를 유지한다.
- 기존 수업의 미디어는 해시 기반 별도 ID로 이전해 제작 미디어와의 번호 충돌을 방지한다. 기존 원본 DB는 유지한다.

## 기능 대응과 현재 범위
| 기존 기능 | 공통 작업에서의 처리 | 현재 상태 |
|---|---|---|
| 캔버스·도안·발표·문서 | 기존 편집 가능한 payload를 같은 작업의 step으로 보관 | 동일 원본 교차 편집 연결 |
| 수업 순서·목표·대상·메모 | 공통 작업 속성 | 저장·복원 연결 |
| 퀴즈·타이머 | 기존 수업 step과 캔버스 활동 형식 보존 | 호환 유지, UI 통합은 후속 |
| 영상·음악 제작 원본 | 별도 프로젝트 payload를 원형 그대로 보존 | 기존 전문 편집기 유지 |
| 영상·오디오·PDF 수업 파일 | 공통 미디어 참조 | 이전·재생·백업 경로 유지 |
| 고급 FilmCraft/SoundCraft 원본 | 기존 공식 프로젝트 저장소 | 기존 경로 유지 |

연결된 원본 step을 수업에서 지우거나 연결된 다중 활동 작업을 제작 목록에서 지우는 동작은 현재 차단한다. 자료를 잃지 않는 분리·전체 작업 삭제 UI를 후속 단계에서 추가한다. ‘보관함 자료 가져오기’는 기존처럼 명시적 복사이며 공통 작업실에서 보관함 원본을 직접 열면 같은 원본을 편집한다.

## 후속 단계
1. 새 작업과 기존 자료의 진입점을 공통 작업실로 통일하고 제작실·수업 준비 메뉴를 병합한다.
2. 연결 자료의 분리·전체 작업 복제·삭제를 작업 단위로 제공한다.
3. 문서의 문단·표·자동 페이지 나눔과 영상·오디오 편집 기능을 같은 작업 화면으로 이전한다. 기존 출력 형식을 유지한다.
4. 같은 작업의 수업 진행 모드를 완성하고 학생 화면의 영상·오디오 재생을 연결한다.
5. 단일 작업 헤더·확대/축소·상황별 패널과 실제 썸네일 중심 홈을 적용한다.
6. 기능·데이터 호환이 검증된 기존 편집기 진입 경로를 정리한다.

## 검증
공통 모델의 원본 보존·중복 ID·미디어 참조 검증, 실제 제작↔수업 화면 이동과 동일 자료 수정, 메모·순서 보존, 두 창의 충돌 차단, 레거시 PDF 이전, 트랜잭션 롤백, 공유 작업의 ZIP 중복 제거와 새 브라우저 복원을 확인한다. 기존 제작실 보관함·수업 준비·ZIP 회귀 검증도 유지한다.


## 공통 작업실 진입 및 화면 통합 (2026-10-20)
주요 메뉴는 홈 / 만들기 / 내 보관함 / 우리 반이다. 만들기는 기존 lesson.html 엔진을 공통 작업실로 사용한다. 홈의 학습지·발표·문서 및 기존 발표·도안 생성 링크, 보관함의 canvas/design/slides/document 원본 열기는 이 작업실로 연결한다. ?new=kind&template=preset와 ?project=id를 지원하며, 프로젝트는 공통 작업으로 연결한 뒤 편집한다. ‘작업 열기’는 기존 단일 자료와 수업 작업을 함께 표시하고 연결 원본은 중복 표시하지 않는다.

편집기·자료 순서·진행 메모가 한 화면에 있다. 편집기로 나가는 ‘자료 편집으로’ 버튼은 제거했다. 원본 내보내기/불러오기와 수업 진행도 같은 화면의 기존 기능을 사용한다. 공통 헤더와 중립적인 작업 배경을 적용하고 390/768/1440px에서 가로 넘침을 검증한다.

아직 영상·음악 제작 프로젝트, 그림 보정, PDF 가공, 고급 원본과 기존 제작실 직접 주소는 호환 편집기를 유지한다. 이 변경은 전체 편집 엔진 이전 완료를 의미하지 않는다. 지원되지 않는 제작 원본을 활동 재생 파일로 변환하지 않는다. 연결 자료 삭제·분리, 단일 실행 취소, 전체 편집기의 상황별 패널 및 확대/축소는 후속 작업이다.


## 작업물 중심 화면 개편 (2026-10-20)
- 편집 배율의 고정 580px·최대 100% 제한을 제거한다. 남은 작업 영역 높이와 너비에 페이지를 맞추고, 확대/축소·현재 배율·페이지 맞춤·선택 확대를 항상 제공한다. 패널 접기와 창 크기 변경은 ResizeObserver로 반영하며 수동 배율은 유지한다.
- 공통 작업실은 홈 이동·제목·저장 상태·실행 취소/다시 실행·학생 화면·수업 진행·내보내기를 하나의 작업 헤더로 제공한다. 사이트 탐색과 캔버스 내부 헤더는 편집 중 숨기고, 파일 명령·수업 정보·진행 메모는 필요할 때 연다. 기존 전문 편집기의 내부 헤더까지 모두 이전한 것은 아니다.
- 홈은 검색 다음에 최근 작업 8개를 배치한다. canvas/slides/document/design 및 수업의 편집 자료 첫 페이지를 저장된 원본에서 직접 미리보기로 만든다. 재생 영상·음악 등 별도 미리보기를 지원하지 않는 자료는 종류 아이콘을 유지한다. 미리보기는 편집 데이터를 수정하거나 미디어를 실행하지 않는다.
- 새 자료 형식은 작은 진입 버튼으로 낮추고 예시는 아래로 이동한다. 본문 섹션의 시작선과 폭을 맞춘다. 도형은 세 열 견본으로 줄이고 글씨·사진 업로드와 분리한다. 업로드 패널에는 현재 작업에 사용한 사진을 다시 넣을 수 있는 썸네일을 제공한다. 교사 활동은 실제 활동 형태의 SVG 미리보기를 제공하며, 활동 선택은 활동 설정 패널로 연결한다.
- 새 원본 생성 시 첫 자료 이름을 작업 이름으로 사용하고, 단일 자료의 작업 이름 수정은 편집 가능한 원본 이름에도 반영한다. 여러 자료가 있는 작업의 제목 변경은 개별 자료 이름을 바꾸지 않는다.

검증은 A4 비율·맞춤·수동 확대·선택 확대, 내부/외부 중복 헤더 제거, 실제 저장 내용의 홈 미리보기, 메모 및 파일 메뉴 열기, 저장·재열기·WAV 백업·복원·학생 화면의 비공개 정보 분리를 포함한다. 한국어 글꼴이 설치된 CI에서도 화면 검증을 수행한다.
