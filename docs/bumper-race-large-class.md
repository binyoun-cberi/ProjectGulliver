# 범퍼 룰렛 대규모 참가·선택지 개선

## 규칙

- 참가자 1~100명, 선택지 1~200개. 참가자 이름은 중복 없이 입력한다.
- 참가자 수에 맞춰 천장 위치를 조정한다. 모든 출발 구슬은 천장·출발 바닥·옆 벽 및 서로와 겹치지 않는다.
- 선택지 16개 이하는 기존 물리 결과함을 쓴다. 17개 이상 또는 균등 배정에서는 넓은 결승 게이트를 사용하며 시작 전에 배정 규칙을 표시한다.
- 게이트의 일반 배정은 입력된 줄 중 무작위 선택이다. 같은 문구가 반복되면 가중치가 된다.
- 중복 금지는 각 입력 줄을 한 자리로 취급해 한 번만 사용한다. 동일 문구 두 줄은 두 자리다. 참가자 수보다 선택지 줄이 적으면 시작하지 않는다.
- 균등 배정은 서로 다른 결과 이름을 모둠으로 취급한다. 모둠별 인원 차이를 최대 1명으로 맞춘다. 균등 배정을 선택하면 전체 결과 배정으로 자동 전환한다. 교사 지정 학생도 정원에 포함하고, 유지하면서 균등 배정이 불가능하면 시작 전에 설명한다.
- 교사 지정 결과는 기존 확인 및 관전 안내를 유지한다. 다른 학생이 지정 자리를 먼저 소비할 수 없도록 예약한다.
- **전체 배정과 우승자 모드는 같은 원래의 긴 범퍼 레이스 코스를 사용한다.** 25초 조기 우회는 더 이상 적용되지 않는다. 90초 이상 걸려 오래 정체된 전체 배정에서만 장애물을 해제하고 외곽벽은 유지한 채 하향 이동을 보조한다. 결과는 여전히 실제 결승 통과 후에만 확정한다.
- 골인 검사는 렌더 프레임이 아닌 물리 단계 직후 수행한다. 단계 내 선형 통과 시각으로 정렬하고 동률은 구슬 번호 순서로 처리한다.
- 기존 긴 코스의 범퍼·핀·회전 구간, 우승자 카운트다운과 접전 옵션을 유지한다.
- 실제 결과 전부를 저장한다. 결과 검색과 모둠별 보기, 긴 문구 줄바꿈을 지원한다.

## 검증

`node --test tests/bumper-race.test.cjs`

- 코스 복원 회귀 검사에서는 두 모드의 긴 코스 길이가 같고, 25초에 조기 우회가 열리지 않는지 확인한다.
- 참가자 1~100명, 모둠 1/4/6/20/100/200개에서 정원·교사 예약 검증.
- 100명×4/30/100/200선택지 및 6모둠 균등의 긴 코스 물리 진행, 결과 누락·중복, 정체 시 안전장치 동작을 검사한다. 실제 기기의 렌더링 속도는 별도 검증 대상이다.
- 100개의 중복 없는 결과와 교사 지정 결과 유지, 100건 저장 및 결과 검색·모둠별 보기 검증.
- 소규모 물리 결과함, 우승자 카운트다운, 중단 후 재시작 회귀 검사.

원격 Chromium CI는 100명×4선택지, 100명×200선택지 중복 금지, 모바일 너비의 100명×6모둠 균등 배정을 검사하고 경기/결과 스크린샷을 보관한다.
