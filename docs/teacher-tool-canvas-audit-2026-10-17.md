# 기존 교사 도구 → 통합 캔버스 사용자 경험 검수 (2026-10-17)

## 범위와 확실성

- 전체 도구 목록(`tools-catalog.js`)을 확인했다. 제작 편집기 8종과 별개로 교사·교실·업무 도구 21종이 있다.
- 기존 **교사 도구 8종**(수업 타이머, 낱말카드·퀴즈, 자리 배정, 학급췍, 칭찬 온도계, 투표판, 범퍼 룰렛, QR)은 실제 Chromium에서 원본을 열고 캔버스로 결과를 가져오는 기존 PR #55 테스트를 완료했다. 이번 작업은 PC·모바일에서 원본 8종을 다시 열고 진입 UI와 화면 크기를 감사한다.
- 아직 직접 실행하지 않은 나머지 **13종**은 구현 코드·저장 방식·화면 구성 검수다. 직접 플레이하거나 모바일에서 전 항목을 조작했다고 주장하지 않는다.
- 평가 기준: (1) 수업 흐름 유지 (2) 캔버스 편집 가능성 (3) 결과의 사실성 (4) 학생 정보 보호 (5) 모바일·전자칠판 조작성 (6) 원본 데이터 보존.

## 핵심 결론

**기능을 한 편집기로 완전히 재구현하기보다는 3단계 통합**이 적절하다.

1. **캔버스에서 실행**: 시간 측정, 퀴즈 진행, 게임·투표 등 상호작용은 기존 엔진을 캔버스의 수업 도구 창으로 실행한다. 독립 사이트는 그대로 유지한다.
2. **수업자료로 추가**: 실행 결과 중 학생에게 보여 줄 수 있는 정적 산출물을 텍스트·도형·사진 등 실제 편집 가능한 페이지로 복사한다. 결과를 추측하거나 예시로 대체하지 않는다.
3. **연결된 자료 다시 읽기(후속)**: 원본 ID·수정일을 기억하고, 사용자가 선택한 때에만 결과를 새로고침한다. 개인정보·비밀 결과물은 원칙적으로 읽지 않는다.

## 연결된 기존 도구 8종의 비평

| 원본 도구 | 원래 강점 | 캔버스 호환의 한계 | 권고 |
|---|---|---|---|

| 낱말카드·퀴즈 | 카드 등록, 뒤집기, TTS, 맞추기 | 문제·답 정적 슬라이드는 카드 뒤집기·소리·맞추기 경험을 잃음 | 정적 카드와 실제 퀴즈 실행을 분명히 나누고, 사용자가 선택한 카드만 가져오기 |

| 칭찬 온도계 | 실시간 점수 및 칭찬 기록 | 캔버스 복사본의 점수는 이후 칭찬에 따라 변하지 않음 | 현재 점수/목표/복사 시각 표시, 새로고침 선택 기능 |

| 범퍼 룰렛 | 움직이는 물리 레이스의 재미 | 정적 결과표를 넣어도 실제 경주는 구현되지 않음 | 게임은 실행 모드에서 유지, 실제 완료된 결과만 문서화 |

## 이번 변경의 실제 범위

- 동일 사이트 교사 도구가 `?studioEmbed=1`로 **캔버스에서 열렸고 실제 캔버스 호스트가 있을 때만** 원본 사이트의 중복 상단 메뉴를 감춘다. 다른 링크나 직접 방문에서는 예전 독립 실행 상태를 보존한다.
- 캔버스 교사 도구 탐색을 더 읽기 쉬운 한 줄 한 도구 방식으로 바꾸고, 저장된 활동/독립 화면 링크는 접는 영역으로 이동한다.
- 교사 도구 창은 상단 조작바 크기에 맞추어 나머지 높이를 실제 도구에 배정한다.
- CI에 PC·모바일의 8종 실행 스크린샷과 화면 폭·누르기 영역 감사를 추가한다.

## 앞으로의 순서

1. 이번 기존 도구의 **공간·용어·탐색 개선**을 먼저 검수/배포한다.
2. '이번 수업 알리미' → '역할 배정·모둠 만들기' → '버스 자리표' 순으로 **편집 가능한 결과 변환**을 확대한다.
3. 사용자가 선택한 결과만 갱신하는 **원본 연결형 자료**를 설계한다. 자동 갱신으로 발표 중 자료나 원본을 덮어쓰지 않는다.
4. QR 외부 엔진의 오프라인 실패, 실제 iPhone Safari, 레이스/카메라 전체 재생 등은 별도 수용 조건을 둔다.
