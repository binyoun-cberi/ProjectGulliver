## 자료와 문항

서른두 개의 독립적인 탐구 상황에 비교표 24개, SVG 모형 그림 8개를 작성했다. 각 상황에는 서로 다른 다섯 질문이 있다. 실제 관찰값으로 오해하지 않도록 표에는 수업용 가상 기록임을, 그림에는 단순화한 모형임을 표시했다. 용해량 표는 실제 설탕·소금의 수치로 제시하지 않는다.

- 발아: 물·온도 조건 비교, 누적 발아 수, 한 가지 조건만 바꾸는 실험 계획.
- 소리: 떨리는 길이, 진동 횟수, 반복 관찰. 크기와 높낮이를 구별한다.
- 자석: 떨어져 작용하는 힘, 거리와 종이 조건, 반복 기록. 움직이지 않았다고 힘이 완전히 0이라고 단정하지 않는다.
- 기체: 밀폐 여부, 같은 기체 양과 거의 일정한 온도, 압축과 되돌림. 입자 자체가 작아지거나 공기가 사라졌다고 설명하지 않는다.
- 용해: 최대 용해량, 남는 용질의 질량, 용해 시간과 최대량의 구별.
- 열: 같은 지점의 시간별 변화, 위치·재료 비교, 고체의 전도. 온도가 매분 같은 양만큼 오른다고 가정하지 않는다.
- 속력: 같은 시간·같은 거리의 비교, cm와 m 단위 통일, 구간 평균. 평균 속력으로 매 순간의 운동을 단정하지 않는다.
- 회로: 닫힌 경로, 전구의 서로 다른 접점, 한 가지씩 점검하기, 회로 모형. 건전지 회로를 사용하며 단락을 실험 지시로 제시하지 않는다.

새 문항의 자료는 각 원본 항목에 보존한다. 생성할 때 같은 탐구 상황의 첫 선택 문항에만 자료를 표시한다. 원래 첫 번째 문제를 제외해도 선택된 다른 문제에 필요한 표·그림과 설명이 붙는다. 기존 문항 ID와 인덱스는 바꾸지 않았다.

## 검증

- 과학 기존 은행·신규 문항·공통 은행 검사 34개 통과.
- 공통 생성·전체 차시 연결·혼합·기존 역사·실제 페이지 DOM 회귀 검사 50개 통과.
- 실제 Chromium에서 여덟 차시의 새 20문항을 강제 선택하여 검사했다. 표 3개와 그림 1개씩 정확히 표시되며, 저장 URL 복원·390px 화면·학생용 정답 숨김·교사용 정답 표시·학생 및 교사용 A4 분할을 확인했다. 회로 인쇄 페이지도 직접 확인했다.
- 신규 검사에서 여덟 차시 × 세 유형 × 네 시드 × 두 세트로 192개 문제지를 생성했다. 각 차시는 연속 두 20문항 세트 사이 중복이 없으며 저장 인덱스로 정확히 복원된다.
- 일부 문항만 선택해도 해당 상황의 자료가 표시되는지, 숫자 계산·누적 기록·단위 변환·표 구조·SVG 구조·정답과 보기의 유일성을 검사한다.
- 과학 차시 수는 여전히 197개이며 모두 20문항 이상이다. docs/science-lesson-coverage.csv의 여덟 차시 수량을 갱신했다.
- 새 데이터 및 검사 경로를 CI에 연결했고 git diff --check를 통과했다.

기존 검사 중 원래의 25문항 묶음을 검증하는 부분은 신규 묶음과 구별해 그대로 검사한다. 실제 차시 용량은 원래 문항과 추가 문항을 합친 수로 검사한다.
