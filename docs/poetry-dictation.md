# 시 받아쓰기

받아쓰기 설정에서 ‘시 받아쓰기’로 이동한다. 초기 작품은 윤동주 「서시」·「새로운 길」과 김소월 「진달래꽃」이다. 위키문헌에 실린 1948년 초판/1925년 시집의 전사본을 확인하고 한국에서 저작재산권 보호기간이 지난 시인의 본문만 사용했다. 공유마당의 윤동주 작품 및 만료저작물 안내도 확인했다. 현대 시인의 작품이나 출판사의 해설·번역은 포함하지 않는다.

원문 출처와 판본·변경 내용을 작품별 데이터에 저장한다. 행과 연의 순서를 유지하되 ‘우르러→우러러’, ‘문들레→민들레’ 등 변경 사항을 밝힌 학습용 표기다. 원문 복제본이라고 표시하지 않는다. 진달래꽃은 1925년 원문 ‘보내드리우리다/뿌리우리다/흘리우리다’를 유지하고 현대 한글과 띄어쓰기로 옮겼다. 옛말·시적 표현이 포함되어 있어 난도 안내 후 교사가 선택한다. 향수는 이번 판본 확인 범위에서 제외하고 임의 전사하지 않았다.

한 행/빈칸/한 연의 3가지 방식과 시작 위치·최대 문제 수를 선택한다. 작품 끝에 도달하면 남은 구절만 사용하며 다른 작품이나 반복 구절로 문제 수를 채우지 않는다. 작품 내 반복 행은 의도된 반복이므로 각각 순서에 맞춰 유지한다. 빈칸은 각 행에서 가장 긴 한글 낱말을 마스킹한다. 제목·시인·판본을 학생용에도 표시한다. 정답은 기본 숨김이며 교사용 토글을 켠 경우에만 화면·인쇄에 보인다. 낱말 난도는 공식 학년/성취기준 판정이 아닌 교사 선택을 돕는 안내다.

공통 받아쓰기 플레이어를 사용하며 반복 1~5번·속도·반복 간격·다음 구절 대기·한국어 음성을 설정한다. 설정 변경 시 이전 재생을 중단한다. URL은 작품·방법·시작 위치·문제 수를 복원한다. 기존 받아쓰기 데이터·과제 ID는 변경하지 않는다.

검증: 데이터 순서·행갈이·ID·잘못된 선택 거부, DOM에서 주소 복원·정답 숨김/표시·빈칸 전환·재생 설정과 기존 받아쓰기/직접 입력 회귀 11개 통과. JS 문법 및 diff 검사 통과. 실제 음성 품질과 브라우저 인쇄 렌더링은 이번 DOM 검사로 보증하지 않는다.
