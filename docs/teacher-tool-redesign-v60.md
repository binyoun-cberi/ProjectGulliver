# 뚝딱교실 6.0 — 교사 도구 공통 기반

## 적용 범위

- `tools-catalog.js`의 제작 관련 8종을 제외한 교사·학급·업무 도구 21종에 같은 내비게이션을 적용한다.
- `gulliver-teacher-ui.css`: **gt-** 접두사의 토큰·구성 요소 스타일 및 반응형 메뉴. 도구 내부의 `.btn`, `.card`, `.topbar` 등을 광역으로 덮어쓰지 않는다.
- `gulliver-teacher-shell.js`: 도구명/유형, 홈·제작실·내 보관함·수업 준비·우리 반 이동, 저장 안내, 전체화면. 기존 `Gulliver.mountShell()`이 만든 화면이 있으면 **하나만 교체**한다.
- `gulliver-teacher-components.js`: 명단을 명시적으로 불러오는 선택기, `idle/saving/saved/error` 저장 상태, 알림, 확인 창, 인쇄·이미지·캔버스 결과 동작용 버튼 생성기.

## 안전 기준

1. **저장 로직 유지.** 6.0은 기존 로컬 저장 키, 게임 엔진, 백업 형식, 캔버스 결과 변환기를 수정하지 않는다. 실제 저장 성공 이벤트가 연결되기 전에는 상단에 '저장됨'이라고 말하지 않는다.
2. **학생용 화면 보호.** `student-view`, `presentation` 상태에서는 공통 상단 메뉴를 숨기며, 자리 배정·버스 좌석·토너먼트의 전용 발표 여백은 별도로 유지한다.
3. **캔버스 중복 방지.** `?studioEmbed=1`이고 같은 출처의 실제 `GulliverTeacherLive` 호스트인 경우에만 공통 메뉴를 감춘다. URL 매개변수만으로 임의의 타사 임베드를 허용하지 않는다.
4. **개인정보 보호.** 공통 명단 선택기는 화면에 개인 이름을 자동 표시하지 않고, 도구가 실제로 선택을 요청할 때만 명단을 복사해서 전달한다. `createResultActions({privateResult:true})`는 캔버스로 추가 버튼을 만들지 않는다.
5. **오프라인 견딤.** 공통 UI는 외부 폰트·CSS·아이콘 CDN을 요구하지 않는다. Tailwind나 QR 생성 엔진처럼 도구 자체가 쓰는 외부 의존성은 후속 개편에서 다룬다.

## 6.1 이후 도구 내부의 연결 예

```js
const ui = window.GulliverTeacherComponents;
const status = ui.createSaveStatus();
document.querySelector('#saveToolbar').append(status);
ui.setSaveStatus(status, 'saving');
try {
  await saveExistingToolData(); // 실제로 성공한 뒤에만
  ui.setSaveStatus(status, 'saved');
  window.GulliverTeacherShell?.updateSaveState('saved');
} catch (error) {
  ui.setSaveStatus(status, 'error');
  window.GulliverTeacherShell?.updateSaveState('error');
}
```

학생 명단과 결과 버튼은 필요한 도구에서만 연결한다. `onCanvas`는 원본 편집기/캔버스 호스트의 실제 가져오기 함수를 전달하고, 호스트가 없는 독립 페이지에 동작하지 않는 버튼을 만들지 않는다. 마니또·마피아·비공개 설정을 원칙적으로 공통 캔버스 결과 액션에 연결하지 않는다.

## 검수

- `node --test tests/gulliver-teacher-ui.test.cjs`: 21개 파일 연결 검사 및 Chrome이 설치된 환경에서 실제 21개 도구 진입·중복 메뉴·모바일 메뉴·학생 모드 검사.
- `teacher-ui-v60-smoke.yml`: PR에서 같은 검사를 수행하도록 등록.
- 6.1~6.5에서는 각 도구의 자체 준비/실행/결과 화면, 저장/재열기, 인쇄, 모바일 실조작을 개별 검수해야 한다. 6.0 자체는 그 단계의 완료를 의미하지 않는다.

## 6.0.1 — 교사용·학생용 두 모니터 연동

교사는 기존 도구에서 설정과 진행을 조작하고, 전자칠판 또는 두 번째 모니터에는 학생용 전용 창을 띄운다. 6.0 공통 상단 메뉴의 **📺 학생창 열기**는 연결된 도구에만 나타난다.

1. 교사용 모니터에서 도구를 열고 **학생창 열기**를 선택한다. 팝업이 차단되면 해당 사이트의 팝업을 허용한다.
2. 생성된 별도 창을 학생용 모니터로 옮기고 **⛶ 전체화면**을 선택한다. 보안상 브라우저가 창 이동이나 전체화면을 자동으로 수행하지는 않는다.
3. 교사용 창에서 내용을 수정하거나 실행하면 학생 창이 자동으로 갱신된다. 창을 닫거나 연결이 끊기면 학생 화면에는 연결 안내를 표시한다.

| 도구 | 학생 화면에 표시하는 항목 | 표시하지 않는 항목 |
| --- | --- | --- |
| 지도안식 원형 타이머 | 제목·시간·진행 단계·다음 활동 | 타이머 설정 패널·저장 인터페이스 |
| 이번 수업 알리미 | 과목·주제·학습 목표·활동 | 입력폼·편집 버튼 |
| 자리 배정 프로그램 | 배정 완료된 자리표 | 앞자리 우선·분리 규칙 등 배정 조건 |
| 마니또 배정 도우미 | 참여자 이름·확인 여부 | 전체 비밀 배정표·개별 배정 상대 |

마니또 학생 창에서 이름을 선택해도 **비밀 결과는 오직 교사용 창의 확인 대화상자에만 나타난다.** 기존 저장 키나 캔버스 연동은 건드리지 않는다. 나머지 17개 교사 도구에는 학생창 버튼을 추가하지 않았으며 후속 도구별 검토를 거쳐 연결한다.

`gulliver-teacher-display.js`는 도구가 등록한 **학생 공개용 스냅샷만** 새 창으로 전달한다. `gulliver-teacher-display-view.js`는 명단·설정 저장소를 읽지 않고, 공개된 정보만 문서에 표시한다. 같은 출처·브라우저 안에서 `BroadcastChannel`을 사용하므로 다른 컴퓨터나 다른 브라우저 프로필 간 원격 송출 기능은 아니다. 학생에게 컴퓨터를 직접 맡기는 경우에는 교사용 화면·개인정보에 접근할 수 없도록 별도 운영 대책이 필요하다.

**검수:** `node --test tests/gulliver-teacher-display.test.cjs`는 공개 데이터 범위와 통신을 확인하며, Chrome 사용 가능 환경에서는 네 도구를 실제로 열어 교사 수정·학생 화면 반영·비공개 조건 비노출을 검사한다. 인터넷 연결이 약해 외부 CDN을 불러오지 못하는 상황도 시뮬레이션한다.

## 6.1 — 타이머·낱말카드·이번 수업 알리미

- 세 도구에 선택 적용하는 `gulliver-teacher-v61.css`를 추가했다. 기존 도구 내부의 `.btn`, `.card`, `.topbar` 등을 전역 덮어쓰지 않고 `gt-v61-*` 영역만 꾸민다.
- **수업 흐름 타이머:** 준비 화면에서 활동 목록과 시간표를 편집한 후 **수업 시작**을 누르면 설정 패널이 사라지고 큰 시계 및 시작·일시정지·다음 활동 버튼이 남는다. **시간표 수정**을 누르면 안전하게 일시정지하고 다시 편집한다. 기존 `lessonCircleTimerV3` 및 중단 시점 복구 형식은 그대로 유지한다.
- **낱말카드·퀴즈:** 카드 관리 화면에서 플래시카드/4지선다/짝 맞추기 실행을 선택한다. 실행 중엔 카드 관리 탭과 자료 편집 목록이 숨겨지고 **카드 준비로** 버튼으로 돌아간다. 한 모니터 발표 모드에서는 학습 통계와 교사용 초기화 옵션까지 숨긴다. `flashQuizMakerPlusV3` 저장 키와 JSON/CSV 자료 형식은 유지한다.
- **이번 수업 알리미:** 안내 내용과 디자인을 입력하는 준비 패널, 같은 창에서 안내판을 크게 표시하는 발표 모드, 별도 학생창을 구분한다. 발표 모드에서 6.0 공통 상단 메뉴와 편집 패널이 숨겨지고 Esc 또는 우상단 버튼으로 복귀한다. 외부 Tailwind CDN 없이도 주요 레이아웃을 유지하는 제한적인 보조 CSS를 넣었다.
- **두 모니터:** **학생창 열기**는 교사창과 별개이며, 학생창으로는 공개 항목만 전송한다. 낱말카드는 앞면/현재 노출된 뒷면, 퀴즈의 현재 선택지 및 답을 공개한 이후의 피드백, 짝 맞추기의 공개 단어와 완료된 연결선만 송출한다. 교사용 탭·명단·저장 설정·정답 ID 매핑을 송출하지 않는다. 브라우저 팝업 허용과 두 번째 화면으로의 실제 창 이동은 교사가 직접 수행한다.
- **캔버스:** 기존 `ClassroomWorkspace` 및 `GulliverTeacherLiveSnapshot` 연결을 유지한다. 게임 자체를 편집 가능한 캔버스 객체로 전환하지 않는다.

**검수:** `tests/gulliver-teacher-display.test.cjs`에 세 도구의 준비→실행→복귀, 낱말카드 비공개 뒷면/정답 표시 시점, 학생창 분리, 모바일 가로 넘침 검사를 추가했다. GitHub Actions의 Chrome 검사에서 실행하며, 저장 복구 및 전체 기기별 수동 검수는 6.5에서 계속한다.
