# 캔버스 활동 요소

타이머, 스톱워치, QR, 수업 안내, 학생 배정, 카드·퀴즈를 캔버스 요소로 추가한다. 같은 추가 메뉴·설정 패널·카드 디자인을 사용하고 다른 글자·도형과 함께 이동·크기 조절·복제·저장·복원한다.

## 데이터와 실행

- `studio-activity-core.js`: 설정 검증, 경과 시간 계산, 실행 제어, 영상 출력 렌더러.
- `studio-activity-classroom.js`: 학생 ID와 배정 결과 검증, 무작위 배정, 수업 준비와 공유하는 문항 파서, 공개 내용 및 공통 그리기 명령.
- `studio-canvas-activities.js`: 공통 패널, 캔버스 렌더링, 정적 SVG 출력.
- 타이머는 페이지 이동과 저장 후 재열기에도 실제 경과 시간을 기준으로 진행한다. 종료 시 정지하며 시작으로 다시 실행한다.
- 학생 배정은 공통 명단의 ID·이름만 복사한다. 모둠 인원, 자리 가로 칸 수, 역할 목록을 설정한다. 캔버스 자체 배정은 조건 없는 무작위 배정이다. 명단·방식·조건을 바꾸면 이전 결과를 지우고 다시 배정한다.
- 기존 모둠·역할 도구의 확정 결과와 자리 도구의 현재 배정을 ‘활동 요소로 추가’할 수 있다. 원본의 고정·기피·희망 조건이나 상담 정보는 복사하지 않는다. 복잡한 배정 알고리즘은 원본 도구를 계속 사용한다.
- 배정은 교사용 결과 미리보기에서 확인한 뒤 명시적으로 공개한다. 다시 배정하면 비공개로 돌아간다. 다시 배정은 실행 취소할 수 있다.
- 퀴즈는 최대 60문항이며 낱말카드 저장 자료나 실행 중인 도구에서 가져올 수 있다. 현재 문제·정답 공개·이전/다음·처음부터를 조작한다. 문제를 넘기면 정답을 다시 가린다.
- QR 생성기는 MIT 라이선스 qrcode-generator 2.0.4와 UTF-8 확장을 로컬 제공한다.

## 두 모니터

`studio-canvas-display.js`는 기존 학생 화면 연결 기능에 canvas 어댑터를 등록한다. ‘학생 화면 열기’로 같은 브라우저의 별도 창을 열고 학생용 모니터로 옮긴다. 교사 화면에서 활동과 페이지를 조작한다. ‘학생 화면 가리기’는 준비 중 안내로 대체한다.

전송하는 내용은 현재 페이지의 공개 SVG뿐이다. 전체 프로젝트, 학생 원본 명단·조건, 퀴즈 문항 배열을 보내지 않는다. 공개 전 배정과 아직 공개하지 않은 정답은 SVG에도 포함하지 않는다. 학생 창은 SVG를 이미지로 표시하며 교사 설정이나 프로젝트 저장소를 읽지 않는다. 각 연결은 무작위 세션 토큰과 별도 창 이름을 사용한다. 교사 화면 종료 시 학생 화면도 종료 안내로 바꾼다.

500ms 간격으로 변경된 상태만 전송하고 3초마다 연결 상태를 확인한다. 공개 SVG가 8MB를 넘으면 전송하지 않는다. 네트워크·다른 브라우저 간 원격 연결 기능은 아니다. 영상 클립·영상 트랙이 있는 페이지는 학생 창에서 지원 안내를 표시하고 실제 영상 재생은 교사 화면에서 진행한다. 오디오를 별도 창으로 복제하지 않는다.

## 출력과 후속 범위

PNG/SVG와 영상 출력은 현재 공개 상태를 반영한다. 조작 버튼·교사용 결과 미리보기는 담지 않는다. 기존 정적 결과 가져오기와 독립 도구는 호환 경로로 유지한다.

후속 범위는 배정 제약 조건 편집의 캔버스 이전, 투표·체크·칭찬과 게임 활동, 영상·오디오의 학생 창 재생이다. 원본 파일 삭제나 기존 저장 자료의 일괄 변환은 수행하지 않는다.
