# 캔버스 활동 요소 1차

타이머, 스톱워치, QR, 수업 안내를 `activity` 요소로 추가한다. 같은 추가 메뉴와 설정 패널을 사용하고 다른 글자·도형과 함께 이동·크기 조절·복제·저장·복원한다. 기존 원본 도구와 결과 가져오기는 호환 경로로 유지한다.

- `studio-activity-core.js`: 설정 검증, 경과 시간 계산, 실행 제어, 영상 출력 렌더러.
- `studio-canvas-activities.js`: 공통 패널, 캔버스 렌더링, 정적 SVG 출력.
- 타이머는 페이지 이동과 저장 후 재열기에도 실제 경과 시간을 기준으로 진행한다. 일시정지와 초기화는 명시적 조작이다. 종료 시 정지하며 시작으로 다시 실행한다.
- 이미지에는 출력 시점의 시간과 QR·안내 내용만 담는다. 조작 버튼은 출력하지 않는다.
- QR 생성기는 MIT 라이선스 qrcode-generator 2.0.4를 로컬 제공하고 UTF-8 확장을 포함한다. 외부 CDN 연결 없이 생성한다.
- 발표 전체화면에는 활동 조작 버튼을 숨긴다. 기존 교사/학생 별도 창 동기화에는 아직 새 활동 요소를 연결하지 않았다.
- 다음 단계: 공통 학생 명단을 참조하는 배정 요소, 문항 기반 활동, 교사/학생 화면 간 활동 제어 동기화. 기존 HTML 파일 삭제나 저장 자료 일괄 변환은 수행하지 않는다.
