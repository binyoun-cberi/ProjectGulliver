# 학급경제 v2 서버 구조

## 목표

ProjectGulliver의 학급경제를 KIDSCade 실시간 게임과 분리된 저빈도 상태 시스템으로 운영한다.

- 학급당 Durable Object 1개
- WebSocket 없음
- 자동 polling 없음
- 사용자가 화면을 열거나 거래를 실행할 때만 요청
- 학생 장부는 전체 장부를 스캔하지 않고 학생별 인덱스 키를 사용
- 월급은 회차 ID로 중복 지급 방지
- 학생 PIN은 평문 저장하지 않고 해시만 저장
- 학생 세션은 12시간 후 만료
- 로그인 5회 실패 시 10분 잠금
- 학급 종료 시 교사가 서버 원장 완전 삭제 가능

## 데이터

한 학급 객체가 다음 상태를 보관한다.

- settings: 화폐, 시작금, 소득세, 소비세, 저축이율, 과태료 상한
- students: 현금, 저축, 자격증, 인증 상태
- certificates
- jobs: 자격조건, 지원자, 채용자, 월급
- items: 가격, 재고
- laws: 시행일, 기본 과태료
- cases: 처분 예정, 확정, 이의신청, 유지, 취소·환급
- payrollRuns: 이미 지급한 급여 회차
- treasury: 정부계좌
- tx:*: 학급 전체 거래장부
- stx:<studentId>:*: 학생별 거래 인덱스

## 월급 정산

교사가 급여 회차를 입력하고 한 번 요청한다.

1. 배정된 직업의 세전 월급 지급
2. 소득세 자동 원천징수
3. 정부계좌 세입 반영
4. 저축계좌 이자 계산
5. payrollRuns에 회차 저장

같은 회차 ID는 다시 실행할 수 없다.

## 법과 과태료

1. 법 등록
2. 시행일 저장
3. 사건 발생일이 시행일보다 빠르면 서버가 처분 등록 거부
4. 사건을 우선 '처분 예정'으로 등록
5. 교사가 확정하면 과태료 차감
6. 학생이 이의 신청 가능
7. 교사가 유지 또는 취소·환급 처리
8. 과태료는 학생 월급 기준 상한과 현재 잔액을 넘지 않음

처분 취소 시 기존 거래를 삭제하지 않고 환급 거래를 새로 남긴다.

## 학생 접근

학생은 다음 세 정보로 로그인한다.

- 학급코드 6자리
- 학생번호 2자리
- PIN 6자리

로그인 성공 후 서버가 임시 세션 토큰을 발급한다. 학생 페이지는 sessionStorage에만 보관하므로 탭을 닫으면 브라우저에서 제거된다.

교사는 PIN을 재발급할 수 있으며 재발급 시 기존 학생 세션도 무효화된다.

## 서버 사용량 원칙

학급경제는 실시간 게임이 아니다. 따라서 잔액 확인을 위해 5초, 10초 단위 polling을 하지 않는다.

대략 30명 한 반이 하루에 아래처럼 사용한다고 가정한다.

- 학생 지갑 조회 4회씩: 약 120 요청
- 구매/저축/지원 등 학생 행동 3회씩: 약 90 요청
- 교사 관리 요청: 약 30 요청

합계 약 240 API 요청/일 수준이다.

월급날에는 학생 수에 따라 거래장부 쓰기가 늘지만 1회의 교사 요청 안에서 처리한다. Durable Object 다중 put의 키 제한을 넘지 않도록 최대 120키씩 나누어 저장한다.

## KIDSCade와의 분리

KIDSCade:
- 게임 계정, 기록, 랭킹: D1
- 실시간 게임방: Durable Object + WebSocket
- 짧은 수명의 게임 상태

ProjectGulliver 학급경제:
- 별도 EconomyClass Durable Object
- 장기 학급 원장
- WebSocket 없음
- polling 없음

둘은 같은 Cloudflare 계정의 무료 사용량을 공유할 수 있지만 코드, Durable Object 클래스, 데이터 상태는 서로 분리한다.

## 배포

ProjectGulliver는 declarative Durable Object exports 설정을 사용한다.

wrangler.jsonc의 GULLIVER_ECONOMY 바인딩과 EconomyClass export가 함께 배포되어야 한다.

    npm install
    npm run deploy

배포 후 health 응답의 classroomEconomy 지원 여부와 학생 로그인/월급/구매/과태료 환급 흐름을 실제 Worker에서 확인한다.
