# 과학 자료 해석 문제지 개선

## 범위와 완료 기준

17개 기존 영역에 독립된 자료 104개를 추가한다. 표의 행·열, 그래프의 값, 관찰 그림의 위치 관계를 이용해서 답해야 하며 설명문에 정답을 그대로 제시하지 않는다. 새 자료의 수치들은 직접 관측한 실제 학생 자료가 아닌 학습용 예시다.

10문항에서는 목표가 겹치는 자료를 제외하면서 원칙적으로 80%를 자료 문항으로 뽑는다. 목표가 같은 기존 자료는 함께 뽑지 않으므로 영역별로 최소 6문항의 자료를 보장한다. 짧은 문제지에도 표와 그림을 각각 포함한다. 긴 15·20문항은 서로 다른 목표를 먼저 소진하고, 남은 수는 적게 사용한 목표부터 채운다. 모든 긴 문제지의 목표가 완전히 달라진다고 보장하지 않는다.

## 이번 첨부 문제지의 회귀 사례

생물과 비생물, 3학년, 10문항, 번호 1ABXN0Z를 다시 생성한다. 키 증가 계산은 한 번만 등장한다. 광합성을 설명에 써 준 뒤 같은 답을 고르는 living-reason-1은 제외한다. 다른 단원의 한살이 단계 암기 그림은 같은 식물의 줄기 방향을 비교하는 관찰 그림으로 교체한다. 성장·번식·이동·색·균류·관찰과 추측·측정 기준·판단에 필요한 관찰 기간을 구별한다.

## 검증

`node --test tests/daily-worksheet-core.test.cjs tests/daily-worksheet-formats.test.cjs`

모든 제공 학년·과학 영역·문항 수·4개 응답 형식·고정 시드의 재현성을 검사한다. 추가로 100개 시드 × 17개 영역의 10문항을 검수하여 자료 최소 수, 자료 출처 중복 금지, 서로 다른 목표 최소 9개를 검사한다. 생물과 비생물은 목표 10개가 모두 달라야 한다. 목표 태그는 자동 교육과정 판정이 아니며 알려진 반복 유형을 묶는 출제 장치다.

브라우저 검증은 17개 영역의 학생용·교사용 5문항 PDF 34개와 첨부 번호의 생물과 비생물 10문항 PDF를 출력한다. 자료는 문제 앞에 제시하고 흑백으로 구별되는 그래프 막대와 숫자를 함께 쓴다. 글자를 과도하게 줄여 한 장에 강제로 맞추지 않으며, 표·그림·문항은 페이지 중간에서 끊지 않는다. 기존 균형 분배와 다른 과목 인쇄 회귀 검사도 유지한다.

## 검수 한계

새 자료와 대표 시드를 사람이 읽고 PDF로 확인하지만, 생성 가능한 모든 조합을 교육학적으로 검증했다는 뜻은 아니다. 일부 기존 개념 확인 문항은 유지한다. 수업과 교과서의 단원 범위에 맞는지는 교사가 최종 확인해야 한다.
