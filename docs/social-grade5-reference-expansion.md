# 5학년 2학기 사회 자료 기반 문항 보강

사용자가 제공한 `알짜정리학습지_사회_5-2` HWP 7개(1단원 1~3, 2단원 1~2, 3단원 1~2)의 본문을 읽어 학습 개념과 범위를 대조했다. 원본 파일은 변경하거나 저장소에 포함하지 않았다. 원문 문장과 빈칸 배열을 옮기지 않고, 다룬 개념을 바탕으로 클라시트 문항과 해설을 새로 작성했다. 첨부된 지도·그림은 복제하지 않았다.

## 보강 범위

| 참고 파일 | 범위 | 기존 은행과 대조한 결과 |
| --- | --- | --- |
| 1단원(1) | 구석기·신석기·청동기·고조선 | 기존 선사·고조선 은행이 이미 20문항 이상 지원 |
| 1단원(2) | 삼국·가야·통일신라·발해 | 기존 고대사 은행이 이미 20문항 이상 지원 |
| 1단원(3) | 고려 건국·사회·외교·문화 | 기존 고려 은행이 이미 20문항 이상 지원 |
| 2단원(1) | 유교·조선 사회·과학·전쟁 | 기존 조선 은행이 이미 20문항 이상 지원 |
| 2단원(2) | 조선 후기·개항·근대 문물 | 마지막 근대 생활 차시 우선 보강 |
| 3단원(1) | 국권 침탈·식민 통치·독립운동 | 문항이 적은 네 차시 우선 보강 |
| 3단원(2) | 광복·정부 수립·전쟁·피해 | 문항이 적은 네 차시 우선 보강 |

9개 차시에 각각 새 문항 25개를 추가하여 **225개**를 보강했다. 그중 18개에는 재구성 정리표·연표를 제공한다. 용어 확인, 사건 순서, 자료의 한계, 생활 변화, 원인·영향을 묻는다. 국가기관 사료를 직접 인용한 표가 아니라 수업을 위해 새로 구성한 표임을 표시한다.

| 차시 | 기존 객관식 풀 | 보강 후 객관식 풀 |
| --- | ---: | ---: |
| 근대 문물과 생활 변화 | 5 | 30 |
| 을사늑약 이후 국권 수호 | 3 | 28 |
| 식민 통치 아래의 생활 | 1 | 26 |
| 3·1 운동과 임시 정부 | 6 | 31 |
| 나라를 되찾기 위한 노력 | 9 | 34 |
| 광복과 생활 변화 | 2 | 27 |
| 대한민국 정부 수립 | 3 | 28 |
| 전쟁 중 생활 | 5(공유) | 28 |
| 전쟁 피해와 영향 | 5(공유) | 27 |

전쟁의 두 차시는 원래 동일한 5문항을 공유했다. 기존 문항도 주제에 따라 3개·2개로 나누고 새 문항 25개씩을 더해, 서로 다른 두 은행 범위로 출제되도록 했다. 따라서 225개는 새 문항의 독립 ID 수이며, 공유된 기존 문항을 중복해서 늘린 숫자가 아니다.

그 결과 5학년 2학기 30개 차시 모두 선택창에 제공하는 7개 유형(객관식·단답·서술·초성·OX·빈칸·틀린 답 고치기)에서 20문항씩 생성 가능하다. 초성에 맞지 않는 문장형 답은 기존 필터로 제외한다. 전 과목·사회 전 학년 보강을 완료했다는 뜻은 아니다. 이번 추가는 차시별 문제 은행과 연결된 성취기준·여러 차시 혼합에 적용되며, 별도 생성기를 사용하는 기존 ‘종합 연습’의 역사 은행을 교체하지 않는다.

## 검증

완료 기준: 보강한 9개 차시와 전체 5학년 2학기 30차시에서 제공 유형별 20문항을 중복 없이 만들고, 기존 사회 생성·저장 주소·혼합·인쇄를 보존한다.

실행 명령: `node --test tests/worksheet-social-modern.test.cjs tests/worksheet-social-audit.test.cjs tests/worksheet-learning.test.cjs tests/worksheet-learning-mix.test.cjs` (`WORKSHEET_JSDOM` 설정).

새 자료 검사: 225개 ID·질문 중복 없음, 주제별 25개, 정답·보기·해설·맥락·출처, 표 18개의 직사각형 구조. 30차시 × 7유형 × 3시드의 **630개 문제지**에서 20문항·재현성을 검증한다. 전쟁 두 범위의 ID가 겹치지 않는 것과 9차시 3문항씩의 27문항 혼합·저장 문항 인덱스 재현도 확인한다.

브라우저 실행 명령: `node --test tests/worksheet-social-modern-browser.test.cjs` (`CHROME_BIN`, `NODE_PATH` 및 로컬 실행에 필요한 Chrome 라이브러리 경로 설정). 9개 차시 20문항 진입, 27문항 초성 혼합, 주소 재열기, 큰 글씨 보존, 390px 넘침 없음, 학생/교사용 A4에 전체 문항이 포함되고 학생용 정답이 숨겨지는 것을 검사한다.
