현재 뚝딱교실 자체에 PhotoCraft 실행 파일이 설치된 것은 아니에요. 아래 버튼은 ArtCraft 공식 사이트가 아닌 독립 운영 사이트로 이동합니다. 학생 사진, 이름, 개인정보가 포함된 자료는 외부 사이트에서 편집하지 마세요.

이렇게 사용해 보세요

  1. 사진 준비 — 활동 사진이나 수업용 그림을 준비해요.
  2. 편집하기 — File → Open에서 파일을 열고 글씨·그림·색을 수정해요.
  3. 저장하기 — File → Export 또는 Save As로 결과를 기기에 내려받아요.
브라우저를 닫거나 새로고침하기 전에 파일을 저장하세요. 이 제작실에는 자동 백업 기능이 없어요.

PhotoCraft는 ArtCraft 오픈소스 프로젝트예요. 기능과 파일 호환성은 개발 단계이며 PC의 최신 브라우저를 권장해요.
